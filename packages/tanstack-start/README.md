Cookie banner, consent dialog, and preference center for TanStack Start. A server function in the root loader resolves each visitor's policy, so the banner is in the first HTML.

c15t is used by [2,100+ sites](https://www.wappalyzer.com/technologies/cookie-compliance/c15t/), including expo.dev, zed.dev, unkey.dev, mintlify.com, and sazabi.com.

## Key Features

- Works with TanStack Start 1.168 and TanStack Router 1.170 or later, on React 18 or 19
- The root route loader resolves each visitor's policy on the server, so the banner is in the first HTML and does not appear late
- Your policy downloads at build time with `consentManifest()` and stays on the server
- Request middleware reads CDN location, language, and Global Privacy Control headers
- Prerendered pages and static hosts work too, with `createConsentRoute()` for same-origin consent requests
- Prebuilt cookie banner, consent dialog, and preference center with a theme system
- Headless hooks for a fully custom design
- Analytics, ads, and pixels follow each visitor's choice through @c15t/integrations: Google Tag Manager, Google Consent Mode v2, GA4, Meta Pixel, PostHog, and more
- IAB TCF 2.4 banner, dialog, and hooks through the @c15t/react/iab subpath
- Translations for 35 languages through @c15t/translations

## Prerequisites

- TanStack Start 1.168 or later and TanStack Router 1.170 or later
- React 18 or 19
- Node.js 20.19 or later
- An [Inth project](https://inth.com) (free sign-up), a [self-hosted backend](https://c15t.com/docs/self-host/quickstart), or offline mode for local development

## Installation

```bash
pnpm add @c15t/tanstack-start@alpha
```

Then add the prebuilt stylesheet to your app-level CSS entry point:

```css
/* src/styles.css */
@import "@c15t/tanstack-start/styles.css";
```

Using several c15t packages? Install [`c15t`](https://www.npmjs.com/package/c15t) and import `c15t/tanstack-start` instead. It is the same code.

## Usage

1. Set `VITE_C15T_BACKEND_URL` to your Inth backend URL in `.env`
2. Add `consentManifest()` from `@c15t/tanstack-start/build` to `vite.config.ts`, before `tanstackStart()`. It downloads your policy at build time and keeps it on the server

```ts
// vite.config.ts
import { consentManifest } from '@c15t/tanstack-start/build';
import { tanstackStart } from '@tanstack/react-start/plugin/vite';
import viteReact from '@vitejs/plugin-react';
import { defineConfig } from 'vite';

export default defineConfig({
  plugins: [consentManifest(), tanstackStart(), viteReact()],
});
```

3. Resolve the consent state in the root route loader with `createConsentStateHandler()` in a server function, and pass it to `ConsentRoot`

```tsx
// src/routes/__root.tsx
import { createRootRoute, Outlet } from '@tanstack/react-router';
import { createServerFn } from '@tanstack/react-start';
import {
  ConsentBanner,
  ConsentDialog,
  ConsentDialogLink,
  ConsentRoot,
} from '@c15t/tanstack-start';
import {
  consentLoaderOptions,
  createConsentStateHandler,
} from '@c15t/tanstack-start/server';

const getConsentState = createServerFn({ method: 'GET' }).handler(
  createConsentStateHandler()
);

export const Route = createRootRoute({
  ...consentLoaderOptions,
  loader: async () => ({ consent: await getConsentState() }),
  component: RootComponent,
});

function RootComponent() {
  const { consent } = Route.useLoaderData();
  return (
    <ConsentRoot state={consent}>
      <Outlet />
      <ConsentBanner />
      <ConsentDialog />
      <ConsentDialogLink>Privacy settings</ConsentDialogLink>
    </ConsentRoot>
  );
}
```

4. For the full setup, see the [TanStack Start quickstart](https://c15t.com/docs/frameworks/tanstack-start/quickstart)

## Hosting

c15t needs somewhere to keep policies and consent records. Pick one:

- **Hosted on [Inth](https://inth.com?utm_source=npm&utm_medium=readme&utm_campaign=oss_readme&utm_content=%40c15t%2Ftanstack-start)**: Inth runs the backend for you. You get policy storage, consent records, audit history, and a dashboard, with no database or server to run. Sign-up is free.
- **Self-hosted**: Run [`@c15t/backend`](https://www.npmjs.com/package/@c15t/backend) on your own server with PostgreSQL, MySQL, or SQLite. You own migrations, backups, and uptime. See the [self-hosting guide](https://c15t.com/docs/self-host/quickstart).
- **Offline**: Choices stay in the browser, with no consent records. Use it for local development, previews, and demos, not production.

The frontend code is the same for Inth and a self-hosted backend. Only the backend URL changes.
