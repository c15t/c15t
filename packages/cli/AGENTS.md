# @c15t/cli

> c15t CLI docs for setup, generation, codemods, authentication, telemetry, and self-host workflows.

These docs ship inside the package so coding agents can read them offline. Open the topic file you need from the list below — paths are relative to this file.

## CLI

Scaffold, migrate, and configure c15t projects from the command line.

- [login & logout](./docs/cli/commands/auth.md): Authenticate the CLI with your hosted c15t account on inth.com.
- [codemods](./docs/cli/commands/codemods.md): Migrate code between c15t versions automatically.
- [generate](./docs/cli/commands/generate.md): Generate consent schema and code for your project.
- [self-host](./docs/cli/commands/self-host.md): Workflow commands for self-hosted @c15t/backend deployments.
- [setup](./docs/cli/commands/setup.md): Interactive scaffolder that installs packages and adds consent components to your project.
- [skills](./docs/cli/commands/skills.md): Install c15t agent skills for AI-assisted development.
- [Global flags](./docs/cli/global-flags.md): Flags that work on every CLI command.
- [Overview](./docs/cli/overview.md): The c15t CLI scaffolds, migrates, and configures consent management in your project.
- [Quickstart](./docs/cli/quickstart.md): Scaffold consent management into a React or Next.js app in under 2 minutes.
- [Telemetry](./docs/cli/telemetry.md): What the CLI collects, why, and how to disable it.
