### Add a Sentry integration

`sentry()` from `@c15t/integrations/sentry` loads Sentry from its CDN, or works with the Sentry SDK your app already runs. Session Replay and user data wait for measurement consent, and error monitoring can too. The CLI offers it in the integration picker.

Enforce user-data denial at the final envelope send stage, including users added by later event processors, feedback, logs and metrics. Strip both `user.*` and `sentry.user.*` attributes from root and child spans while denied. Keep late SDK initialization synchronized, honor vendor denial for every feature category, and stop Replay without flushing when the integration is removed. Preserve app-initiated Sentry shutdowns after re-grant.

Keep Replay running and retain the SDK bundle when an app recreates an equivalent script configuration. Publish the `@c15t/scripts/sentry` compatibility export alongside the integration.
