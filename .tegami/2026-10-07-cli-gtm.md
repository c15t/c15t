### Replace a Google Tag Manager container from the CLI

`c15t gtm` reads a published container id, or a JSON export from GTM, and
prints the `@c15t/integrations` calls that replace it. An id that is not a
`G-`, `AW-`, `DC-` or `GT-` id is still printed, with a warning. The command
does not edit the project and does not keep the GTM snippet.
