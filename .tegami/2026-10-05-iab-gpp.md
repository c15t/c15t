### Add IAB Global Privacy Platform support

Every framework can now install the GPP 1.1 CMP API (`__gpp`) and keep its
GPP string in step with the visitor's choices:

- React, Next.js and TanStack Start: render `ConsentGPP` from
  `@c15t/react/gpp` (`c15t/react/gpp`) inside the consent provider or
  `ConsentRoot`. Its props are the GPP options.
- Vue and Nuxt, Svelte and SvelteKit, and Astro: set the `gpp` option on the
  plugin, module, provider or integration. `gpp: true` uses the defaults. The
  GPP code loads as its own chunk, only when the option is set.
- `@c15t/browser`: call `mountGPP(client)` from `@c15t/browser/gpp`, or on a
  script-tag page load `c15t.gpp.js` next to `c15t.js`, `c15t.headless.js`
  or `c15t.iab.js`. The script installs a `__gpp` stub as soon as it runs and
  reads a `gpp` object from the page's config; `gpp: false` turns it off.
- `createConsentRuntime()` takes `gpp` with
  `loadGPP: () => import('@c15t/iab/gpp')`, and `createGPP()` from
  `@c15t/iab/gpp` mounts the API against any consent kernel.

Plain React and `@c15t/browser` bundles that do not import the GPP entries
contain none of its code.

The matched policy rule decides whether a section applies. Under an `iab`
rule, the TC String the TCF CMP confirmed becomes the `tcfeuv2` section. A
rule with the `preferences` or `opt-out` right gives US visitors their state
section (`usca`, `usva`, `usco` and 13 others), or the MSPA US National
section when the region is unknown or the state has no section
(`usFallback: 'none'` turns that off), or when `usApproach` is `'national'`.
A rule without those rights gets no section. Sale, sharing and targeted
advertising opt-outs follow the `marketing` category, notices follow the
rule's rights, and the GPC signal is reported where the section has a GPC
subsection.

The API answers `ping`, `addEventListener`, `removeEventListener`,
`hasSection`, `getSection` and `getField`, takes over calls queued by a GPP
stub, and serves iframes through the `__gppLocator` frame. When another CMP
that has already loaded owns `__gpp`, c15t leaves it in place: the `gpp`
option reports the conflict to `onError`, `ConsentGPP` logs it, and
`mountGPP()` and `createGPP()` throw. Indiana, Kentucky, Maryland and Rhode
Island sections are not encoded yet; visitors there get the fallback.
