### Support nonce- and hash-based Content Security Policies in Astro

Set `Astro.locals.c15t.nonce` from your own middleware, which runs after c15t's.
Every inline `<script>` and `<style>` the c15t components render carries it, and
the browser runtime puts it on the scripts and stylesheets it adds.

```ts
// src/middleware.ts
import { defineMiddleware } from 'astro:middleware';

export const onRequest = defineMiddleware(async (context, next) => {
	const nonce = crypto.randomUUID();
	if (context.locals.c15t) {
		context.locals.c15t.nonce = nonce;
	}
	const response = await next();
	response.headers.set(
		'content-security-policy',
		`script-src 'self' 'nonce-${nonce}'; style-src 'self' 'nonce-${nonce}'`
	);
	return response;
});
```

Per-request nonces keep working across `<ClientRouter />` navigations.
`<ConsentBanner />` takes the nonce as a `nonce` prop, and
`<ConsentBannerDeferred />` passes it to its server island. Astro's island
loader is an inline script without a nonce, so a nonce-only policy blocks the
island until it allows that script too.

With Astro's CSP on (`security.csp`, or `experimental.csp` in Astro 5), the
integration adds hashes for c15t's inline scripts, theme stylesheet (for every
experiment arm) and inline `scripts` entries, so you no longer need
`'unsafe-inline'`. Inline `scripts` from a `clientEntrypoint` module can't be
hashed ahead of time. The browser logs a console error with each missing hash.
Add it to `scriptDirective.hashes`, or move scripts without callbacks into the
integration's `scripts` option.

The boot payload renders as a
`<script type="application/json" data-c15t-config>` block built by
`buildConfigJSON()` from `@c15t/astro/server`, instead of a script that sets
`window.__c15tAstroConfig`. Pages that still use `buildConfigScript()` keep
working.

Put the page's nonce on your own gated tags too, as in
`<script is:inline type="text/plain" data-c15t-category="measurement" nonce={Astro.locals.c15t.nonce}>`.
When the page has a nonce, c15t activates only gated tags that carry it. It
skips the others, marks them `data-c15t-activated="untrusted"` and logs a
warning. Under `'strict-dynamic'` this stops an injected tag from running once
its category is granted.
