## Let Inth run your consent backend

You need a backend to store consent records outside the visitor's browser. Inth handles the backend and database for c15t's framework integrations, browser package and headless API.

Connect your application to an Inth project with the [framework setup guide](/docs/frameworks). Inth also serves your consent policy. Static sites can use Inth without their own application server.

Browser-only mode keeps choices on the visitor's device and creates no remote consent records. Use it for development and tests. Not recommended for production environments.

You can [self-host the c15t backend](/docs/self-host/overview) when your team needs to operate the service. Your team then owns the database, backups, updates and availability.
