Run Vite before a separate `tsc`, `vue-tsc` or `svelte-check` step so the
generated module exists on a clean checkout. Starting the development server
also generates it for editor checks. The plugin does not run during a
standalone type check.

If your build tool restores cached application output, it restores that
output's snapshot too. After a backend policy edit, force a new application
build instead of restoring the previous build artifact.
