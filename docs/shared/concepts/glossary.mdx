<section id="glossary">
  ## Core terms

  | Term | Meaning |
  | --- | --- |
  | `explicitChoice` | Latest receipt per explicitly confirmed optional category |
  | `effectivePermissions` | Current processing permissions after defaults, choices, expiry and restrictions |
  | `promptRequirement` | Outstanding choice, notice or no interaction |
  | `noticeDismissal` | Local record of dismissing the current notice; not consent or proof of delivery |
  | `optOutDirectives` | Standing privacy requests kept separately from choices |
  | `subject` | Subject identifiers; local identification does not prove server association |
  | `selectedConsents` | Editable displayed draft, before effective privacy restrictions |
  | `resolution` | Matched, unconfigured, no-match or failed policy outcome |
  | `model` | Policy permission model: opt-in, opt-out or IAB |
  | `mode` | Provider transport factory: hosted, offline or custom |

  ## Privacy and IAB terms

  GPC is Global Privacy Control. Exact browser detection maps to categories through
  `privacySignals.gpc.denyCategories`. It can record a standing opt-out directive,
  never consent. Geography is policy-matching context, not permission authority.

  TCF is the IAB Transparency and Consent Framework. The integration targets TCF 2.3.
  GVL is its Global Vendor List. IAB targets require confirmed TC authority and still
  apply category denials, scope and privacy restrictions.
</section>
