<section id="intro">
  ## Configure rules and presentation

  Use `mode: offline({ policyRules })` for local rules or a hosted transport for
  backend resolution. Put visual configuration in `presentation.prompt` and
  `presentation.preferences`. Required actions and persistent rights come from
  the policy. Read `resolution`, `policyRule` and `promptRequirement` through the
  provider hooks. Unconfigured, no-match and failed outcomes use safe opt-in
  choice behavior. Failed initialization keeps the first layer hidden while retrying.

  See the [React policy guide](/docs/frameworks/react/policy-packs) for a complete
  example and [policy concepts](/docs/frameworks/react/concepts/policy-packs) for
  the dated preset reviews.
</section>
