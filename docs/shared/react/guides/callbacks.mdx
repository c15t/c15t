<section id="intro">
  ## Events and callbacks

  Use `onChoiceRecorded({ snapshot, confirmed, actionAt })` for direct decisions.
  Use `onPermissionsChanged({ snapshot, previous })` for processing permissions.
  Registration does not replay either callback. Hydration, expiry and GPC can
  change permissions without recording a choice. A repeated unchanged save
  renews the supplied receipts and invokes the choice callback once.

  Notice dismissal and privacy opt-out have separate kernel events. They never
  call the choice callback or use the consent-saving endpoint.
</section>
