  ## Read request context

  ```tsx
  import { useSnapshot } from '@c15t/react';

  export function LocationDetails() {
    const { location, resolution } = useSnapshot();
    return (
      <pre>
        {JSON.stringify({ location, status: resolution.status }, null, 2)}
      </pre>
    );
  }
  ```

  Location is request context, not permission authority. The policy rule selects
  behavior. Use `usePolicyResolution` for matched, unconfigured, no-match and failed
  outcomes. There is no automatic country-to-permission table.

  For deterministic previews, configure provider `overrides` with country and
  region. Developer GPC overrides remain distinct from detected browser signals.
  Do not convert missing request data into an override or a saved choice.
