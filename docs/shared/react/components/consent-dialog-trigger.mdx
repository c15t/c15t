<section id="intro">
  `ConsentDialogTrigger` is a floating button that opens the consent dialog when clicked. Users can drag it to any corner of the screen, and the position persists across sessions. Use it to give users a persistent way to manage their privacy settings. Opening the dialog through the trigger hides the floating button until the dialog closes.
</section>

<section id="customization">
  ## Persistent visibility

  ```tsx
  <ConsentDialogTrigger showWhen="always" icon="fingerprint" />
  ```

  The default `always` keeps preferences accessible before and after a choice and
  while a notice is required. Use `never` only when another persistent control
  provides that access. The old consent-dependent visibility mode is removed.

  Use `icon="branding"`, `icon="fingerprint"`, `icon="settings"` or your own icon.
  For app-owned controls such as theme or support, compose those separately beside
  a `ConsentDialogLink`. The old toolbar component is not exported in v3.
</section>
