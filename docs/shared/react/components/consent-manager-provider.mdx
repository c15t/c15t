<section id="intro">
  `ConsentProvider` owns the consent kernel for a React tree. It initializes the
  selected transport, exposes snapshot selectors and commands through context,
  and wires optional persistence, script loading, network blocking, and IAB
  support.

  Render every c15t component and hook below one provider.
</section>

<section id="legal-links">
  ## Legal Links

  Configure only the links your consent UI should expose:

  ```tsx
  import { ConsentProvider, hosted } from 'c15t/react';

  <ConsentProvider
    options={{
      mode: hosted({ url: 'https://your-instance.c15t.dev' }),
      legalLinks: {
        privacyPolicy: { href: '/privacy', target: '_self' },
        cookiePolicy: { href: '/cookies', target: '_self' },
        termsOfService: {
          href: 'https://example.com/terms',
          target: '_blank',
          rel: 'noopener noreferrer',
          label: 'Terms of Service',
        },
      },
    }}
  >
    {children}
  </ConsentProvider>
  ```
</section>

<section id="overrides">
  ## Overrides

  `overrides` forces location, language, or GPC signals. Use it for QA and
  previews; production deployments should normally rely on request signals.

  ```tsx
  <ConsentProvider
    options={{
      mode: hosted({ url: 'https://your-instance.c15t.dev' }),
      overrides: { country: 'DE', region: 'BY', language: 'de-DE' },
    }}
  >
    {children}
  </ConsentProvider>
  ```
</section>

<section id="policy-packs">
  ## Policy Packs

  Hosted mode resolves policies on the backend. Offline mode accepts policy
  packs directly through `offline()`:

  ```tsx
  import { ConsentProvider, offline } from 'c15t/react';
  import { policyPackPresets } from 'c15t';

  <ConsentProvider
    options={{
      mode: offline({
        policyPacks: [
          policyPackPresets.europeOptIn(),
          policyPackPresets.worldNoBanner(),
        ],
      }),
      overrides: { country: 'DE' },
    }}
  >
    {children}
  </ConsentProvider>
  ```
</section>
