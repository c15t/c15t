<section id="intro">
  `Frame` conditionally renders its children based on consent state. When consent for the specified category is not granted, a placeholder is shown instead. Children are not mounted at all until consent is given, preventing any network requests or script execution.
</section>

<section id="customization">
  ## Custom placeholder

  ```tsx
  <Frame
    category="experience"
    placeholder={<p>Open privacy settings to enable this content.</p>}
  >
    <InteractiveWidget />
  </Frame>;
  ```

  `Frame.Root`, `Frame.Title` and `Frame.Button` let you compose a placeholder.
  The button opens preferences. Frame never expands the policy category scope;
  configure the category on the policy before using it.
</section>
