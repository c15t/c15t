<section id="content">
  Every theme token is converted to a `--c15t-*` CSS custom property at runtime. You can override these variables in your stylesheet without using the JavaScript theme API.

  Accordion-specific `--accordion-*` overrides remain supported on the root, an ancestor, or the component itself. Their defaults resolve where each property is used, so importing the generic accordion and consent widget styles in a different order does not change their appearance. These defaults are no longer declared on `document.documentElement`; read the rendered element's computed styles when inspecting its spacing or colors.

  ## Overriding Variables

  Override in your stylesheet:

  ```css
  :root {
    --c15t-primary: #8b5cf6;
    --c15t-surface: #fafafa;
    --c15t-radius-md: 1rem;
  }

  /* Dark mode overrides */
  .dark,
  .c15t-dark {
    --c15t-primary: #a78bfa;
    --c15t-surface: #18181b;
    --c15t-text: #fafafa;
  }
  ```

  ## Scoped Overrides

  Target specific components by scoping variables:

  ```tsx
  <div className="checkout-consent">
    <ConsentBanner />
  </div>
  ```

  ```css
  /* Only affect c15t components inside .checkout-consent */
  .checkout-consent {
    --c15t-surface: #f0f9ff;
    --c15t-radius-lg: 1.5rem;
  }
  ```
