  ## What Are Component Slots?

  Component slots let you target specific parts of the stock consent UI with framework-native attributes. In React v3, slots are configured through `ConsentManagerProvider.options.components`.

  Use slots after the stock component APIs and design tokens:

  - If the change is semantic, prefer tokens first. For example, the stock banner footer background comes from `theme.colors.surfaceHover`.
  - If the component part is correct but you need a local tweak, use a component slot.

  ## Using Slots

  Pass slot props in the provider `components` object:

  ```tsx
  <ConsentManagerProvider
    options={{
      components: {
        banner: {
          card: {
            className: 'rounded-xl shadow-lg',
            style: { maxWidth: '600px' },
          },
          footer: { className: 'border-t border-black/10 px-6' },
          title: { className: 'text-xl font-bold tracking-tight' },
        },
        button: {
          primary: { className: 'rounded-full px-6' },
        },
      },
    }}
  >
    <ConsentBanner />
  </ConsentManagerProvider>
  ```

  Each slot accepts a React attribute bag. `className`, `style`, `data-*`, ARIA attributes, and other valid HTML attributes are preserved.

  `noStyle` on a component still removes c15t's base classes only. Slot props and consumer props continue to apply.

  ## Common Slot Paths

  | Path | Description |
  |------|-------------|
  | `banner.root` | Root wrapper for the consent banner portal content. |
  | `banner.overlay` | Backdrop overlay rendered behind the banner. |
  | `banner.card` | Main card container for banner content and actions. |
  | `banner.header` | Header region containing title and description. |
  | `banner.title` | Banner title text element. |
  | `description.banner` | Banner description text element. |
  | `banner.footer` | Footer container for banner action buttons. |
  | `banner.actionGroup` | Nested button group inside the banner footer. |
  | `tag.banner` | Branding tag rendered above the consent banner card. |
  | `dialog.root` | Root wrapper for the consent dialog modal. |
  | `dialog.overlay` | Backdrop overlay rendered behind the dialog. |
  | `dialog.card` | Main dialog card container. |
  | `dialog.header` | Dialog header region containing title and description. |
  | `dialog.title` | Dialog title text element. |
  | `description.dialog` | Dialog description text element. |
  | `dialog.content` | Dialog content region, typically holding `ConsentWidget`. |
  | `manager.footer` | Footer used by the compound dialog and widget layouts. |
  | `tag.dialog` | Branding tag rendered below the stock consent dialog card. |
  | `manager.root` | Root wrapper for the consent widget/preferences panel. |
  | `accordion.root` | Accordion region listing consent categories. |
  | `manager.actionGroup` | Nested button group inside the widget footer. |
  | `tag.manager` | Branding tag rendered below the standalone consent widget. |
  | `button.primary` | Shared primary button styling across consent components. |
  | `button.secondary` | Shared secondary button styling across consent components. |
  | `iab-banner.root` | Root wrapper for the IAB consent banner. |
  | `iab-banner.overlay` | Backdrop overlay rendered behind the IAB banner. |
  | `iab-banner.card` | Main card container for IAB banner content. |
  | `iab-banner.header` | Header region for IAB banner title/description. |
  | `iab-banner.footer` | Footer container for IAB banner actions. |
  | `tag.iab-banner` | Branding tag rendered above the IAB banner card. |
  | `iab-dialog.root` | Root wrapper for the IAB consent dialog. |
  | `iab-dialog.overlay` | Backdrop overlay rendered behind the IAB dialog. |
  | `iab-dialog.card` | Main card container for IAB dialog content. |
  | `iab-dialog.header` | Header region for IAB dialog title/description. |
  | `iab-dialog.footer` | Footer container for IAB dialog actions. |
  | `tag.iab-dialog` | Branding tag rendered below the IAB dialog card. |

  The React v3 slot contract is shared with `@c15t/vue` through `@c15t/schema/config`.
