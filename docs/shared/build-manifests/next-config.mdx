Wrap your existing Next.js config object or function:

{/* example: fragment */}

```ts title="next.config.ts"
import { withConsentManifest } from 'c15t/next/build';

export default withConsentManifest(config, {
	backendURL: 'https://your-project.inth.app',
});
```

`next build` and `next dev` fetch `${backendURL}/manifest` and write
`c15t-manifest.ts`. `next start` never fetches. Keep the file out of Git.
