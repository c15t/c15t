Install `c15t@alpha` alongside `@c15t/browser` for the build plugin. Add it to
your existing Vite plugins:

{/* example: fragment */}

```ts title="vite.config.ts"
import { consentManifest } from 'c15t/build';

consentManifest({ backendURL: 'https://your-project.inth.app' });
```

Vite generates `src/c15t-manifest.ts` before compilation and development
startup. Keep the generated file out of Git. In your browser entry point,
add these options to the existing `init()` call:

{/* example: fragment */}

```ts title="src/main.ts"
import { consentManifest } from './c15t-manifest';

init({
	backendURL: 'https://your-project.inth.app',
	manifest: consentManifest,
	mode: 'manifest',
});
```

Keep your scripts and UI options. The browser uses the snapshot without a
manifest fetch. Policies that need geography still call `/init` when the
browser has no country. Consent saves and IAB vendor-list requests can still
use the backend. Rebuild after editing policy, translations or vendors;
a failed snapshot fetch stops the build. A script-tag site without a build
step cannot run this hook.

For policy updates without a rebuild, omit the build plugin and snapshot.
Keep the original backend `/init` setup or use a runtime `manifestURL`.
