<include src="../build-time-manifest-notes.mdx" />

`outputFile`, `exportName` and `importSource` change the generated file. Set
`importSource: '@c15t/nextjs/static'` if you install `@c15t/nextjs` directly,
and `rootDir` if Next.js runs outside the app directory.

For policy updates without a rebuild, remove `manifest` from
`consentOptions` and use [runtime manifest caching](/docs/frameworks/next/optimization#reuse-cached-policy-data).
