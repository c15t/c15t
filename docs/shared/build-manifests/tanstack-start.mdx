Add `consentManifest` before the TanStack Start plugin in your existing Vite
configuration:

{/* example: fragment */}

```ts title="vite.config.ts"
import { consentManifest } from 'c15t/tanstack-start/build';

plugins: [
	consentManifest({ backendURL: 'https://your-project.inth.app' }),
	tanstackStart(),
	viteReact(),
];
```

Use your absolute backend URL. The build appends `/manifest`. Vite writes
`src/c15t-manifest.ts` before compiling the app, both during a production build
and when a development server starts.

Bind the backend URL and the snapshot once:

<include src="../examples/tanstack-start/consent-options.mdx" />

Keep the `.server.ts` suffix. `__root.tsx` also runs in the browser, and Start's
compiler removes the server function's handler from the browser build along
with this import, so the snapshot stays on the server. If browser code ever
uses `consentOptions` directly, TanStack Start's import protection fails the
build instead of shipping the manifest to every visitor.

Pass `consentOptions` to the existing server function in `__root.tsx`:

<include src="../examples/tanstack-start/build-manifest-server-fn.mdx" />

Keep the `createServerFn().handler()` declaration in your application module
so TanStack Start's compiler can split its server code. The root loader and
`ConsentRoot` keep their existing setup. If you mount `createConsentServerRoute`,
pass it the same object so browser initialization uses the same policy:

{/* example: fragment */}

```ts title="src/routes/api/c15t/$.ts"
handlers: createConsentServerRoute({ ...consentOptions, proxy: true }),
```

Keep `src/c15t-manifest.ts` out of Git and generate it on every build.
`outputFile`, `exportName` and `importSource` customize the generated module.
Omitting `importSource` or passing `undefined` uses
`c15t/tanstack-start/static` for the type import.
Apps that install `@c15t/tanstack-start` directly set
`importSource: '@c15t/tanstack-start/static'`.

<include src="../vite-build-manifest.mdx" />

For policy updates without a rebuild, remove the build plugin and the
`manifest` line from `consentOptions`, and use [runtime fetching](/docs/frameworks/tanstack-start/rendering#await-consent-in-the-loader).
