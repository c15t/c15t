Declare the options once, next to `c15t.config.ts`:

<include src="../examples/nextjs/pages-consent-options.mdx" />

Spread them into each page's `resolveConsent`:

{/* example: fragment */}

```tsx title="pages/index.tsx"
const state = await resolveConsent({ ...consentOptions, req });
```

And pass them to the manifest API route:

{/* example: fragment */}

```ts title="pages/api/c15t/manifest.ts"
import { createPagesApiHandlers } from 'c15t/next/pages';

import { consentOptions } from '@/c15t.server';

export default createPagesApiHandlers(consentOptions).manifest;
```

Pass the same object to the optional init API route. Import `c15t.server.ts`
only from `getServerSideProps` and API routes.

<include src="../build-time-manifest-notes.mdx" />

If you install `@c15t/nextjs` directly, set `importSource: '@c15t/nextjs/static'`.
In a monorepo, set `rootDir` to the app directory.

For policy updates without a rebuild, remove `withConsentManifest` and the
`manifest` line, and use [runtime manifest caching](/docs/frameworks/next/optimization#reuse-cached-policy-data).
