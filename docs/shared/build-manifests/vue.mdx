Add `consentManifest` from `c15t/build` to your existing Vite plugins, alongside
the Vue and c15t Vue plugins:

{/* example: fragment */}

```ts title="vite.config.ts (plugins option)"
import { consentManifest } from 'c15t/build';

export default {
	plugins: [
		// Keep your existing framework plugins here.
		consentManifest({ backendURL: 'https://your-project.inth.app' }),
	],
};
```

Without `backendURL`, the plugin reads `VITE_C15T_BACKEND_URL`. When
`vite build` or `vite dev` starts, the plugin fetches the policy and serves it
as `snapshot` from `c15t/generated`. Import it in `src/main.ts` and add these
options to the existing Vue plugin setup:

{/* example: fragment */}

```ts title="src/main.ts"
import { snapshot } from 'c15t/generated';

app.use(c15tVue, {
	backendURL: 'https://your-project.inth.app',
	manifest: 'client',
	manifestSnapshot: snapshot,
});
```

The browser resolves policy from the bundled snapshot without fetching
`/manifest` or `/init`. Without `geoURL` or explicit location overrides it
uses the unknown-location policy, so configure a fallback rule. The bundle
includes the policy and resolver. Keep your scripts and other plugin options.

When the build has no snapshot, as in `vite dev` after a failed fetch,
`snapshot` is `undefined`, and the plugin fetches
`${backendURL}/manifest` instead.

Keep the original backend `/init` setup when you need backend geolocation.
