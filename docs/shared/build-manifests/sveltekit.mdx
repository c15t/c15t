Add the manifest plugin to your existing Vite configuration:

{/* example: fragment */}

```ts title="vite.config.ts"
import { consentManifest } from '@c15t/svelte/vite';

plugins: [
	consentManifest({
		backendURL: 'https://your-project.inth.app',
		outputFile: 'src/lib/c15t-manifest.ts',
	}),
	sveltekit(),
];
```

Vite generates the file before compilation, including when development starts.
Keep it out of Git. In the root layout's server load, give `loadConsent` the
snapshot in addition to its existing options:

{/* example: fragment */}

```ts title="src/routes/+layout.server.ts"
import { consentManifest } from '../lib/c15t-manifest';
import type { LayoutServerLoad } from './$types';

export const load: LayoutServerLoad = async (event) => ({
	prefetch: await loadConsent(event, {
		backendURL: 'https://your-project.inth.app',
		manifest: consentManifest,
		shared: building,
	}),
});
```

Keep the quickstart's `building` import for your SvelteKit version.
`loadConsent` resolves locally from the snapshot using this request's inputs.
For prerendered pages in a server deployment, add a route that resolves from
the same snapshot:

{/* example: fragment */}

```ts title="src/routes/api/c15t/[...path]/+server.ts"
import { createSvelteKitConsentRouteHandlers } from '@c15t/svelte/kit';

import { consentManifest } from '../../../../lib/c15t-manifest';

export const { GET } = createSvelteKitConsentRouteHandlers({
	backendURL: 'https://your-project.inth.app',
	manifest: consentManifest,
});
```

In the root layout's script block, point browser initialization at that route
while keeping saves on the backend:

{/* example: fragment */}

```ts title="src/routes/+layout.svelte script block"
const mode = hosted({
	url: 'https://your-project.inth.app',
	initURL: '/api/c15t',
	assertDecisionInputs: true,
});
```

Keep passing `mode` and `data.prefetch` to `ConsentManagerProvider`. A
prerendered page resolves each visitor through the route after hydration;
request-rendered pages reuse the server result. This route needs a SvelteKit
server. Static hosts use the browser setup from
[build a static site](/docs/frameworks/sveltekit/rendering#build-a-static-site).
