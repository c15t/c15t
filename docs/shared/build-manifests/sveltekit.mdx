Add the plugin before `sveltekit()`. Keep the generated file out of Git:

{/* example: fragment */}

```ts title="vite.config.ts"
import { consentManifest } from '@c15t/svelte/vite';

plugins: [
	consentManifest({
		backendURL: 'https://your-project.inth.app',
		outputFile: 'src/lib/server/c15t-manifest.ts',
	}),
	sveltekit(),
];
```

Bind the backend URL and snapshot once. Under `src/lib/server`, SvelteKit
keeps both out of browser code:

<include src="../examples/sveltekit/consent-options.mdx" />

Spread them into the root layout's `loadConsent`:

<include src="../examples/sveltekit/build-manifest-layout-server.mdx" />

For prerendered pages on a server deployment, add a route with the same
options:

<include src="../examples/sveltekit/build-manifest-route.mdx" />

Then point browser initialization at it. Saves still go to the backend:

{/* example: fragment */}

```ts title="src/routes/+layout.svelte script block"
const mode = hosted({
	url: 'https://your-project.inth.app',
	initURL: '/api/c15t',
	assertDecisionInputs: true,
});
```

Static hosts use [build a static site](/docs/frameworks/sveltekit/rendering#build-a-static-site)
instead.
