## What c15t is

c15t is an open-source consent runtime with components for each framework. You
install it in your app's code, and it reads policy and stores consent records
through a backend: [Inth](https://inth.com), a
[self-hosted c15t backend](/docs/self-host/overview), or no backend in offline
mode.

| Capability | c15t v3 |
| --- | --- |
| License | Apache-2.0, every published package |
| Framework support | Next.js, TanStack Start, React, Nuxt, Vue, Astro, Svelte, SvelteKit, a script tag for plain HTML, a headless JavaScript runtime, and React Native |
| Consent records | Stored by Inth or by `@c15t/backend` on PostgreSQL, MySQL or SQLite |
| Policies | Region-based policy rules, with presets for Europe, US states, California, Québec, Canada and more |
| Vendor loading | Consent-aware loaders in `@c15t/scripts`, a network blocker, and gated embeds |
| Google Consent Mode v2 | Through the [Google tag](/docs/integrations/google-tag) and [Tag Manager](/docs/integrations/google-tag-manager) integrations |
| IAB TCF | TCF 2.4 through `@c15t/iab` |
| Presentation | Stock components, theme tokens, component slots, or [headless hooks](/docs/customization/overview) |

c15t does not scan your site for cookies or generate privacy policies.

## Compare hosted consent platforms

These products run the banner and its configuration as a hosted service. The
second column summarizes what each vendor's own pages describe; follow the link
for the sources and a test plan.

| Product | What its published pages describe | Pricing basis they state |
| --- | --- | --- |
| [Cookiebot](/docs/comparisons/cookiebot) | Hosted banner setup and cookie scanning | Plans by domain and subpage count |
| [Didomi](/docs/comparisons/didomi) | A console for managing notices, plus SDKs and APIs | No public price on the linked page |
| [iubenda](/docs/comparisons/iubenda) | Cookie consent, consent records and privacy and cookie policy generators | Included pageviews, with extra usage billed |
| [OneTrust](/docs/comparisons/onetrust) | Scheduled scanning, cookie inventories and a consent transaction database | No public price on the linked page |
| [Osano](/docs/comparisons/osano) | Cookie classification, blocking, customizable banners and reporting | How often `Osano.js` is served, estimated from daily active users |
| [Usercentrics Web CMP](/docs/comparisons/usercentrics) | A hosted website consent product | Plans with monthly session and domain allowances |

## Compare browser libraries

These are libraries you install in the page and configure in code.

| Library | What its published pages describe | Consent records |
| --- | --- | --- |
| [CookieConsent v3](/docs/comparisons/cookieconsent-v3) | Categories and a preference modal, with setup for HTML, React, Vue and Angular | You send them to your own backend from its callbacks |
| [Klaro](/docs/comparisons/klaro) | Service configuration and annotated script tags; a hosted version also exists | Not described in the linked setup guide |
| [react-cookie-consent](/docs/comparisons/react-cookie-consent) | A React consent bar with accept and decline callbacks and cookie helpers | Not described |
| [Silktide Consent Manager](/docs/comparisons/silktide-consent-manager) | A free banner with no domain or user limits, Google Consent Mode v2 and translations | Not described |
| [tarteaucitron.js](/docs/comparisons/tarteaucitron) | A service panel that stores choices in a cookie, with built-in service definitions | A browser cookie |

## Test before you choose

Run the same test on each tool you shortlist, with your own app and vendors:

1. Load the site in a private window and check DevTools Network. Optional vendor
   requests should not start before a choice.
2. Reject, reload, and confirm the vendors stay blocked.
3. Accept, then reopen preferences and withdraw. Check what the vendor still
   does after withdrawal.
4. Check where the record of each choice is stored and how you retrieve it.

For c15t, follow the [framework guide](/docs/frameworks) with
[Inth](https://inth.com), then run the [verification guide](/docs/guides/verify-consent).
Review legal requirements separately from these results.

Competitor sources were reviewed on 10 September 2026. Pricing changes; check
each vendor's current terms for your region and traffic.
