## Understand what you are integrating

c15t resolves a policy, combines it with stored choices and privacy signals,
and exposes effective permissions. Its components render the actions required
by that policy. Its script and embed integrations use permission to control
optional work.

A banner does not automatically block code installed elsewhere. Follow
[verification](/docs/guides/verify-consent) to check the actual vendor requests,
rejection, reloads and preference changes.

## Using a coding agent

Read the installed package's `AGENTS.md` and linked Markdown for version-matched
instructions. On the website, use the documentation index and individual
Markdown pages before loading the full context bundle. Identify the framework,
router and hosting shape before choosing a recipe.
