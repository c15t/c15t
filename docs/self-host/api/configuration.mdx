## Create an instance

```ts
import { c15tInstance } from '@c15t/backend';

const backend = c15tInstance({
  database: { dialect: 'sqlite', filename: ':memory:' },
  trustedOrigins: ['https://example.com'],
  manifest: {
    policyRules: [
      {
        id: 'default',
        match: { isDefault: true },
        model: 'opt-in',
        prompt: 'choice',
      },
    ],
  },
});
```

Use a persistent database for deployment and run migrations before serving
requests. v3 uses `database` instead of the old adapter option. The instance
exposes `handler(request)` and `dispose()`. Dispose test and short-lived instances
to release resources.
