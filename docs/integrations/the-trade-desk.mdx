The `theTradeDeskPixel` helper keeps The Trade Desk off the page until `marketing` consent is granted.
Remove direct snippets and tag manager copies so they cannot bypass c15t.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `advertiserId` | Required | Public advertiser ID. Trimmed; blank or invalid values skip loading. |
| `pixelIds` | Required | Nonempty array of trimmed public pixel IDs. An invalid or blank entry skips the whole integration. |
| `enableCookieSyncing` | Vendor default | Passed to initialization when supplied. `false` disables syncing, but does not prevent all cookies or make preconsent loading safe. |
| `dataProcessingOption` | None | Limited data use policy, such as policies `['LDU']` and region `'US-CO'`. This is separate from consent. |
| `scriptUrl` | `https://js.adsrvr.org/up_loader.3.0.0.js` | Loader override. Blank values use the default. The Walmart DSP variant is `https://azjs.adsrvr.org/thetradedesk-ads/up_loader.3.0.0.js`. |

## Loading and revocation

After marketing consent, the helper creates `ttdConversionEventsLayer` and the
`ttdConversionEvents` function. Calls enter the queue as arguments objects. It
queues `init` and one `event`, then inserts the asynchronous loader. Limited data
use is forwarded as `dataProcessingOption` during initialization and
`data_processing_option` on the event. Existing callable SDK methods are
preserved.

The SDK reads TCF and GPP signals where applicable. Those signals control vendor
behavior after loading; they do not replace the outer c15t gate. Send later
conversion calls only while marketing and applicable vendor consent remain
granted.

The vendor documents no complete browser stop or teardown API. Keep c15t's
default `reloadOnConsentRevoked` enabled. Without reload, existing code, requests
and frames can continue until navigation. The retained loader avoids duplicate
initialization on regrant, but does not unload the SDK.

The Trade Desk documents the `TDID` identifier cookie on `adsrvr.org`, with a
one-year lifetime. A read-only request using the guide's sample IDs returned a
`TDID` cookie even with cookie syncing disabled. The served SDK also reads local
storage debugging flags and can read existing GA4 cookies when configured.
The browser monitor blocks collection and does not establish a complete cookie
inventory or account event delivery.

For CSP, the guide lists `js.adsrvr.org` for scripts and `insight.adsrvr.org` and
`match.adsrvr.org` for frames. Realtime conversion connections use
`insight.adsrvr.org`. Account options can add hosts.

Sources: [official Universal Pixel guide](https://open.thetradedesk.com/provider/docsApp/GuidesProvider/data/doc/TrackingTagsUniversalPixel)
and [privacy policy](https://www.thetradedesk.com/legal/privacy).

## Verify The Trade Desk

In a fresh browser profile, deny consent and allow only an unrelated category.
Confirm that no vendor requests, globals, cookies, local storage or session storage
appear. Grant `marketing` and check the loader URL against your account snippet.
Withdraw consent and confirm the page reloads. The Trade Desk must stay blocked on the
new page. Inspect storage in DevTools as well as Network.
