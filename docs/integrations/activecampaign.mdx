## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `accountId` | Required | ActiveCampaign account ID. |
| `email` | Unset | Known contact email passed to `setEmail` after consent. |
| `category` | `marketing` | Consent condition for the whole loader. |
| `scriptUrl` | `https://prism.app-us1.com/prism.js` | Custom or proxied loader URL. Blank values use the default. |

Missing or blank required values log an error and never load.

## Loading and revocation

After consent, the helper creates the callable `pgo` queue, sets its alias and timestamp, configures the account, and sets `setTrackByDefault(false)`. After the SDK loads it calls `process('allowTracking')`, which sends the page request itself. It does not add a second `process` call.

Keep `reloadOnConsentRevoked` enabled. The fetched runtime has no documented stop command. Removing its script cannot stop running code, clear stored identifiers or cancel requests. The permitted tag stays in the DOM for same-page regrant to avoid installing a second runtime. The next denied page does not load the tag.

ActiveCampaign uses first-party tracking cookies. Cookie names and other storage can vary with the vendor runtime and account configuration. Inspect your own deployment after grant.

The official `prism.js` endpoint returned a redirect to a malformed URL and a 403 during verification. The vendor CDN runtime at `https://diffuser-cdn.app-us1.com/diffuser/diffuser.js` returned JavaScript and was exercised with an explicit `scriptUrl` override. The helper keeps the official default and does not silently substitute a different URL.

## Verify ActiveCampaign

Check for no `prism.js`, `pgo`, `prismGlobalObjectAlias`, cookies or browser storage before consent and after unrelated consent. Grant marketing and confirm the vendor runtime replaces the queue. Verify the page request with your own configured account. Revoke and check that the next denied page does not load the tracker.
