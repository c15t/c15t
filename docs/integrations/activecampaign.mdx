## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `accountId` | Required | ActiveCampaign account ID. |
| `email` | Unset | Known contact email passed to `setEmail` after consent. |
| `category` | `marketing` | Consent condition for the whole loader. |
| `scriptUrl` | `https://diffuser-cdn.app-us1.com/diffuser/diffuser.js` | Regional or proxied loader URL. Blank values use the default. |

Missing or blank required values log an error and never load.

## Loading and revocation

After consent, the helper creates the callable `pgo` queue, sets its alias and timestamp, configures the account, and sets `setTrackByDefault(false)`. After the SDK loads it calls `process('allowTracking')`, which sends the page request itself. The helper sends no duplicate `process` call at initial load. A same-page regrant calls `process('allowTracking')` again on the existing runtime.

Keep `reloadOnConsentRevoked` enabled. The fetched runtime has no documented stop command. Removing its script cannot stop running code, clear stored identifiers or cancel requests. The permitted tag stays in the DOM for same-page regrant to avoid installing a second runtime. The next denied page does not load the tag.

ActiveCampaign uses first-party tracking cookies. Cookie names and other storage can vary with the vendor runtime and account configuration. Inspect your own deployment after grant.

The default loads ActiveCampaign's Diffuser SDK directly from its vendor CDN. During verification, the `prism.js` URL from ActiveCampaign's tracking snippet redirected to `diffuser.js,?` and returned 403. The clean CDN URL returned JavaScript, accepted the same `pgo` queue, and initialized the tracker. The default bypasses that malformed redirect. Use `scriptUrl` for another region or a proxy and verify that it serves the matching ActiveCampaign runtime.

## Verify ActiveCampaign

Check for no `diffuser.js`, `pgo`, `prismGlobalObjectAlias`, cookies or browser storage before consent and after unrelated consent. Grant marketing and confirm the vendor runtime replaces the queue. Verify the page request with your own configured account. Revoke and check that the next denied page does not load the tracker.
