## Configure the LinkedIn Insight Tag

Copy the partner ID from LinkedIn Campaign Manager under Data, Signals manager,
Insight Tag. Remove the original Insight Tag snippet and its `<noscript>`
tracking image.

<CommandTabs command="@c15t/integrations@alpha" mode="install" />

```ts title="src/consent-scripts.ts"
import { linkedinInsights } from '@c15t/integrations/linkedin-insights';

export const scripts = [linkedinInsights({ id: 'YOUR_PARTNER_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `id` | Required | Partner ID. The helper trims it, sets it as `_linkedin_partner_id` and appends it to `_linkedin_data_partner_ids`. Empty or whitespace-only values throw. |
| `scriptSrc` | `https://snap.licdn.com/li.lms-analytics/insight.min.js` | Loader URL override. A blank value falls back to the default. |

## Loading and revocation

`linkedinInsights` uses the `marketing` category. Before marketing is allowed,
c15t sets no LinkedIn globals and loads nothing from LinkedIn. When marketing
becomes allowed, the helper sets the partner ID globals, defines the `lintrk`
queue, then loads `insight.min.js`.

On revocation the helper removes the script element and calls no LinkedIn API,
so the page reload is what stops the tag. `window.lintrk` stays defined until
then.

## Guard your own lintrk calls

The Insight Tag tracks page views itself. Conversions your code sends through
`lintrk('track', ...)` need their own check, because `window.lintrk` still
exists after revocation. Check the permission first, then that the tag is set
up:

```ts title="src/track-signup.ts"
export function trackSignup(marketingAllowed: boolean) {
  if (!marketingAllowed || typeof window.lintrk !== 'function') return;
  window.lintrk('track', { conversion_id: 1234567 });
}
```

Pass the current marketing permission from your framework, for example
`useConsent('marketing')` in React. Use the conversion ID from your LinkedIn
conversion. `@c15t/integrations/linkedin-insights` exports no event wrapper.

## Verify the LinkedIn Insight Tag

After you allow marketing, `insight.min.js` loads from `snap.licdn.com`, and
`window._linkedin_data_partner_ids` in the console contains your partner ID.
Trigger one guarded conversion and check that its request to LinkedIn appears.
Then revoke marketing. Until the page reloads, calling `trackSignup` sends
nothing.
