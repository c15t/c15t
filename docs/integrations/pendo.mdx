Pendo records product usage and shows in-app guides. The c15t `pendo` helper
waits until the `measurement` category is allowed before it downloads the
Pendo agent, and it calls `pendo.initialize()` only once the agent has loaded
and consent is still granted. Until then, c15t defines no `pendo` global.

When the visitor withdraws, the helper calls `pendo.stopSendingEvents()`. If
consent comes back on the same page, it calls `startSendingEvents()` and keeps
the same visitor identity. c15t still reloads the page by default.

## Configure Pendo

Copy the web agent API key from Pendo. Then delete Pendo's install snippet from
your app, and any tag manager copy, so Pendo can't load outside c15t. Pass
visitor and account metadata only when your app has permission to identify the
visitor.

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `apiKey` | Required | Web agent API key. Trimmed and URL-encoded into the default loader URL. If it's missing or blank, c15t logs an error and never loads Pendo. |
| `visitor` | Unset | Visitor metadata passed to `pendo.initialize()`. Replaces any `visitor` in `initializeOptions`. |
| `account` | Unset | Account metadata passed to `pendo.initialize()`. Replaces any `account` in `initializeOptions`. |
| `initializeOptions` | Unset | Other `initialize()` options, such as `disableCookies`, `localStorageOnly`, `excludeAllText` and `cookieDomain`. |
| `category` | `measurement` | Consent category or condition that must be allowed before the agent loads. |
| `scriptUrl` | `https://cdn.pendo.io/agent/static/<apiKey>/pendo.js` | Custom, regional or proxied agent URL. A blank value uses the default. |

## Loading and revocation

When the category is allowed, the helper adds the agent as an async script. It
doesn't queue calls before the agent loads. After the script loads, it checks
consent again and calls `initialize()` with your options. If the visitor
withdrew while the agent was downloading, the helper doesn't initialize. It
initializes on the next grant instead. Calling `pendo()` again with equal
options, such as on a rerender, returns the same script, so Pendo initializes
only once per page.

If the loaded script doesn't define `window.pendo`, for example because the API
key or `scriptUrl` is wrong, the helper logs
`pendo: loader did not install the Pendo API` and does nothing else. It doesn't
throw.

On withdrawal, the helper keeps the agent on the page and calls
`stopSendingEvents()`. On a later grant it calls `startSendingEvents()` and
doesn't initialize a second time. This keeps the visitor's identity across
reversible consent changes.

The helper never calls `clearSession()`, because that starts a new anonymous
visitor and can send identification events. If a visitor signs out while Pendo
is loaded and consent is granted, call `pendo.clearSession()` yourself before
you identify the next visitor. Don't call it to withdraw consent, or while
consent is denied. To remove data Pendo already collected, use your account's
data deletion or Do Not Process controls.

Stopping events doesn't delete Pendo's cookies or local storage, and guides
already on the page stay there. Keep `reloadOnConsentRevoked` enabled if the
next page must run without Pendo loaded.

## Cookies and storage

Pendo storage keys usually start with `_pendo_` and include the app ID. Cookie
behavior depends on `initialize()` options such as `disableCookies`,
`localStorageOnly` and `cookieDomain`.

## Verify Pendo

Filter the DevTools Network panel by `pendo.io`. Before consent, and with only
an unrelated category allowed, check that no Pendo request, `pendo` global,
cookie or storage entry appears. Allow measurement and confirm that the agent
loads and initializes once. Withdraw consent and confirm the page reloads with
Pendo blocked.

If you set `reloadOnConsentRevoked: false`, withdraw consent and check that
`pendo.isSendingEvents()` returns `false`. Grant again and confirm that event
sending resumes without a new anonymous visitor. Test guide behavior with your
own account.

If the console shows `pendo: loader did not install the Pendo API`, check the
API key and `scriptUrl`.
