## Configure OneDollarStats

OneDollarStats needs no API key. The helper loads the tracker and forwards
each setting you pass as a `data-*` attribute.

<CommandTabs command="@c15t/integrations" mode="install" />

```ts title="src/consent-scripts.ts"
import { oneDollarStats } from '@c15t/integrations/one-dollar-stats';

export const scripts = [oneDollarStats()];
```

## Options

Every setting is a string without the `data-` prefix. Setting names use
lowercase letters, digits and hyphens. The helper throws on any other name and
on a non-string value. Unknown names are forwarded, so newer tracker settings
work.

| Option | Default | Behavior |
| --- | --- | --- |
| `hostname` | None | Bare host, optionally with a port. Overrides the event hostname on every host, including production. A scheme, path, query or fragment throws. |
| `devmode` | None | `'true'` records local visits. Local testing needs `hostname` as well. |
| `autocollect` | None | `'false'` turns off automatic page view and click collection. |
| `hash-routing` | None | `'true'` tracks hash routes. `'false'` omits the attribute, because the tracker turns hash routing on whenever it is present. |
| `url` | None | Custom collection endpoint. |

The helper always loads `https://assets.onedollarstats.com/stonks.js` and has
no loader URL option. The tracker follows client-side navigation itself. See
the [vendor reference](https://docs.onedollarstats.com/installation) for its
settings.

## Loading and revocation

`oneDollarStats` uses the `measurement` category. The tracker loads only while
measurement is allowed. On revocation the helper removes the script element
and calls no OneDollarStats API.

The tracker installs history hooks and event listeners that removing its
script cannot undo, so the c15t reload on revocation is what stops it. Keep
`reloadOnConsentRevoked` enabled.

## Verify OneDollarStats

After you allow measurement, the `stonks.js` request appears and its script
element carries the `data-*` settings you passed. Navigate between routes and
check that each one sends a page view.
