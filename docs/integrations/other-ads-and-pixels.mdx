## AdRoll

AdRoll retargets site visitors with ads and measures conversions. The helper sends the first `pageView` for you. Waits for `marketing` consent.

<include src="../shared/examples/javascript/adroll-scripts.mdx" />

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `advertiserId` | `string` | Yes | Advertiser ID from Analytics > Insights > Website > View Pixel. |
| `pixelId` | `string` | Yes | Pixel ID from the same snippet. |
| `scriptUrl` | `string` | No | Loader URL. Defaults to `https://s.adroll.com/j/<advertiserId>/roundtrip.js`. |

**When consent is withdrawn:** AdRoll has no API to stop it, so the helper leaves it on the page. Keep c15t's default `reloadOnConsentRevoked` so the page reload removes it.

- In AdRoll, set Settings > Data Collection > Visitor Consent to **Use your existing Consent Banner**. Otherwise AdRoll can load its own banner.
