## Vector

Vector identifies the people and companies visiting your site and builds advertising audiences from their activity. Waits for `marketing` consent.

<include src="../shared/examples/javascript/vector-scripts.mdx" />

| Option | Type | Required | Description |
| --- | --- | --- | --- |
| `pixelId` | `string` | Yes | Pixel ID from **Settings > Pixel** in Vector. |
| `scriptUrl` | `string` | No | Custom SDK URL. Defaults to `https://cdn.vector.co/pixel.js`. |

**When consent is withdrawn:** Vector has no stop API, so c15t reloads the page to stop it. Keep `reloadOnConsentRevoked` on.
