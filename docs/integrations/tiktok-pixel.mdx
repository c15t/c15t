## Configure the TikTok Pixel

Copy your TikTok Pixel ID. The helper adds it to the loader URL as `sdkid`.

<CommandTabs command="@c15t/integrations" mode="install" />

```ts title="src/consent-scripts.ts"
import { tiktokPixel } from '@c15t/integrations/tiktok-pixel';

export const scripts = [tiktokPixel({ pixelId: 'YOUR_PIXEL_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `pixelId` | Required | Pixel ID sent in the loader URL. The helper trims it. Empty or whitespace-only values throw. |
| `scriptSrc` | `https://analytics.tiktok.com/i18n/pixel/events.js` | Loader base URL override. The helper appends `?sdkid=<pixelId>&lib=ttq`. A blank value falls back to the default. |

## Loading and revocation

`tiktokPixel` uses the `marketing` category. Before marketing is allowed, c15t
defines no `ttq` queue and loads nothing from TikTok. When marketing becomes
allowed, the helper sets up `ttq` the way TikTok's base code does, queues one
`ttq.grantConsent()` and `ttq.page()`, then loads `events.js`.

On revocation the helper keeps the pixel and calls `ttq.revokeConsent()`. If
the visitor allows marketing again before the page reloads, it calls
`ttq.grantConsent()`.

## Guard your own ttq calls

The helper sends the page view. Events your code sends through `ttq.track` or
`ttq.identify` need their own check. After revocation `window.ttq` still
exists, so its presence does not mean marketing is allowed. Check the
permission first, then that the pixel is set up:

```ts title="src/track-purchase.ts"
export function trackPurchase(marketingAllowed: boolean, value: number) {
	if (!marketingAllowed || typeof window.ttq?.track !== 'function') return;
	window.ttq.track('CompletePayment', { currency: 'USD', value });
}
```

Pass the current marketing permission from your framework, for example
`useConsent('marketing')` in React. `@c15t/integrations/tiktok-pixel` exports no
event wrapper.

## Verify the TikTok Pixel

After you allow marketing, a request to
`analytics.tiktok.com/i18n/pixel/events.js` carries your pixel ID as `sdkid`,
and the pixel sends one page event. Trigger one guarded event and check that
its request appears. Then revoke marketing. Until the page reloads, calling
`trackPurchase` sends nothing.
