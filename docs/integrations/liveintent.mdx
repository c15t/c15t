## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `category` | `marketing` | Consent condition for the entire loader, including compound category conditions. |
| `tagId` | Required | Trimmed public tag ID, URL-encoded into the filename. Blank or invalid values log an error and skip loading. |
| `scriptUrl` | `https://b-code.liadm.com/<tagId>.min.js` | Account loader override. Blank values use the default. |
| `events` | None | Plain event objects queued once after the initial grant. Use the fields from your account's event tags. |

## Loading and revocation

The helper creates `liQ` as an array after marketing consent, queues optional
initial event objects and inserts one asynchronous loader. The runtime replaces
that array with its client. For later events, call `window.liQ.push` only while
marketing and any applicable vendor consent remain granted. A function queue or
method-and-arguments tuples will not match LiveConnect's event format.

LiveIntent documents additional TCF requirements where GDPR applies, along with
GPP and legacy US privacy signals. c15t's marketing category does not replace a
TC string. Zeta's guide names purposes 1 through 4, but the public example bundle
served during verification required more purposes and special features. Confirm
your account's production tag and applicable requirements with LiveIntent. Do not
request extra purposes just to satisfy the public example.

There is no documented stop or withdrawal command for the complete runtime.
Keep c15t's default `reloadOnConsentRevoked` enabled. With reload disabled,
existing clients, listeners and sync frames can continue until navigation. The
helper retains one loader to avoid reinjection when consent is granted again.

The served code contains `_lc2_fpi`, `_lc2_fpi_js`, `_li_dcdm_c`, `_li_ss` and
`lidids.*` cookie writes, plus `_li_duid` and `_li_ss` local storage. Some cookie
paths request up to 730 days; browsers can shorten that lifetime. Partner and
account settings can add storage. Main hosts include `b-code.liadm.com`,
`idx.liadm.com`, `rp.liadm.com`, `rpr.liadm.com` and `i.liadm.com`.

## Verify LiveIntent

In a fresh browser profile, deny consent and allow only an unrelated category.
Confirm that no vendor requests, globals, cookies, local storage or session storage
appear. Grant `marketing` and check the loader URL against your account snippet.
Withdraw consent and confirm the page reloads. LiveIntent must stay blocked on the
new page. Inspect storage in DevTools as well as Network.
