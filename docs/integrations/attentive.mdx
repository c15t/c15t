## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `siteSlug` | Required | Attentive-provided slug in the tag URL. |
| `category` | `marketing` | Consent condition for the whole loader. |
| `scriptUrl` | `https://cdn.attn.tv/<siteSlug>/dtag.js` | Custom or proxied loader URL. Blank values use the default. |

Missing or blank required values log an error and never load.

## Loading and revocation

The helper loads `dtag.js` at the end of the body after consent. It creates no custom queue. Attentive can then download additional bundles, create an iframe, display signup units and track events.

Keep `reloadOnConsentRevoked` enabled. Attentive has no documented client API that reliably stops all tag behavior. Removing a tag cannot unload executed code, cancel pending requests or remove every iframe. Undocumented enable/disable methods are not used as a shutdown guarantee. The next denied page does not load the tag.

Attentive can set `_attn_`, `__attentive_id`, `__attentive_dv`, `__attentive_ss_referrer`, `__attentive_pv`, `__attentive_cco`, `attntv_mstore_email`, `attntv_mstore_phone`, `__attentive_ceid`, `__attentive_domain` and `__attentive_client_user_id`. Some identifiers last 390 days. Inspect cookies and both browser storage areas for your tag configuration.

## Verify Attentive

Check for no `dtag.js`, Attentive globals, iframe, cookies or browser storage before consent and after unrelated consent. Grant marketing and inspect the real tag and chained bundles. Revoke and confirm the next denied page does not load them. Test signup and delivery only with your own account.
