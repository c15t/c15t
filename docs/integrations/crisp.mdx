The c15t `crisp` helper keeps the Crisp chat widget off the page until
`functionality` has consent. Until then, c15t does not set
`window.CRISP_WEBSITE_ID`, so no chat widget shows. If the visitor withdraws
consent, c15t removes the script element. The widget stays on the page until
c15t reloads the page, which c15t does by default.

## Configure Crisp

Copy the website ID from your Crisp installation snippet, where it is assigned
to `CRISP_WEBSITE_ID`.

<CommandTabs command="@c15t/integrations" mode="install" />

```ts title="src/consent-scripts.ts"
import { crisp } from '@c15t/integrations/crisp';

export const scripts = [crisp({ websiteId: 'YOUR_WEBSITE_ID' })];
```

## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `websiteId` | Required | Written to `window.CRISP_WEBSITE_ID`. The helper trims it. Empty or whitespace-only values log an error and the script does not load. |
| `locale` | None | Widget locale, written to `window.CRISP_RUNTIME_CONFIG.locale`. |
| `sessionMerge` | None | Merges anonymous sessions into token-backed sessions. Written to `CRISP_RUNTIME_CONFIG.session_merge`. |
| `tokenId` | None | Session continuity token, written to `window.CRISP_TOKEN_ID`. |
| `cookieDomain` | None | Cookie domain, written to `window.CRISP_COOKIE_DOMAIN`. |
| `cookieExpiry` | None | Cookie lifetime in seconds, written to `window.CRISP_COOKIE_EXPIRE`. |
| `safeMode` | `false` | Pushes `['safe', true]` to `$crisp` before the loader. |
| `scriptSrc` | `https://client.crisp.chat/l.js` | Loader URL override. A blank value falls back to the default. |

## Loading and revocation

`crisp` uses the `functionality` category. The chat widget loads only while
functionality is allowed, so link another support contact for visitors who
deny it. On revocation the helper removes the script element and calls no
Crisp API. The running widget stays until c15t reloads the page.

Before loading, the helper creates `window.$crisp` as an empty array unless
your page already made one. Commands your code pushed onto `$crisp` earlier
stay queued, and Crisp runs them when it loads. They never reach Crisp while
functionality is denied.

## Verify Crisp

After you allow functionality, the request to `client.crisp.chat/l.js` appears
and the chat launcher shows. Before that, `window.CRISP_WEBSITE_ID` is
undefined.
