## Options

| Option | Default | Behavior |
| --- | --- | --- |
| `category` | `marketing` | Consent condition for the entire loader, including compound category conditions. |
| `advertiserId` | Required | Public advertiser ID from the generated v2 snippet. Trimmed and URL-encoded in the loader path. |
| `pixelId` | Required | Public pixel ID from that snippet. Invalid or blank required IDs log an error and skip loading. |
| `scriptUrl` | `https://s.adroll.com/j/<advertiserId>/roundtrip.js` | Account-specific v2 loader override. Blank values use the default. |

## Loading and revocation

The helper starts through the browser script loader, including saved grants.

After marketing consent, the helper sets the account globals, creates the official
array queue, adds `setProperties`, `identify` and `track` stubs and queues one
`pageView`. Each queued call contains a method name and an arguments object. It
then inserts the asynchronous advertiser-specific v2 loader. The generic
`https://s.adroll.com/j/roundtrip.js` is a different, legacy v1 loader.

Send additional events and identity data through the documented AdRoll API only
while marketing and applicable vendor consent remain granted. The helper does
not send email addresses or other identity data automatically.

AdRoll documents no public stop or teardown API. Keep c15t's default
`reloadOnConsentRevoked` enabled. With reload disabled, already loaded code,
partner pixels and timers can continue until navigation. The retained loader
prevents duplicate initialization on regrant. Removing its tag cannot unload it.

NextRoll's notice names `__adroll`, `__ar_v4`, `__adroll_shared` and
`__adroll_fpc` tracking cookies. The served code also writes consent cookies,
local storage such as `__adroll_consent_data`, session storage such as
`adroll_tpc` and `adroll_flgs`, and an `adroll` IndexedDB database. Account and
partner configuration affect the inventory. Storage can be initialized when the
loader evaluates, which is why the whole loader waits for consent.

The monitor uses public house-account IDs with collection blocked. Official
sample IDs return access-denied responses. Successful house-loader execution does
not prove your account's configuration, conversion delivery or partner behavior.
The lifecycle probe also blocks the JSONP consent check, so it proves SDK
construction and consent gating without claiming queue replay or full account
initialization.

## Verify AdRoll

In a fresh browser profile, deny consent and allow only an unrelated category.
Confirm that no vendor requests, globals, cookies, local storage or session storage
appear. Grant `marketing` and check the loader URL against your account snippet.
Withdraw consent and confirm the page reloads. AdRoll must stay blocked on the
new page. Inspect storage in DevTools as well as Network.
