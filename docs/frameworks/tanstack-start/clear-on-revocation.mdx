## Configure cleanup

Gating stops new requests, but it leaves the cookies and storage keys a vendor
already wrote. List the ones each optional category owns and pass them to the
`ConsentRoot` in `src/routes/__root.tsx`. When that category is denied, c15t
deletes them:

{/* example: fragment */}

```tsx title="src/routes/__root.tsx (partial)"
import type { ClearOnRevocationConfig } from 'c15t';

const clearOnRevocation: ClearOnRevocationConfig = {
	measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
	marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
};

<ConsentRoot
	state={consent}
	backendURL={backendURL}
	scripts={scripts}
	clearOnRevocation={clearOnRevocation}
>
```

`ConsentRoot` takes `clearOnRevocation` as a top-level prop, not inside
`options`. It reads the value once, when it mounts; remount it to change the
list.
