## Render the preference dialog

`ConsentDialog` is the modal preference center. Render it once inside
`ConsentRoot`, next to the banner. It opens when the banner's Customize button,
a `ConsentDialogLink`, a `ConsentDialogTrigger` or your own code makes `dialog`
the active surface:

{/* example: fragment */}

```tsx title="src/components/privacy-menu-item.tsx"
import { useSetActiveUI } from 'c15t/tanstack-start';

export function PrivacyMenuItem() {
  const setActiveUI = useSetActiveUI();
  return (
    <button type="button" onClick={() => setActiveUI('dialog')}>
      Cookie preferences
    </button>
  );
}
```

Under an IAB policy the dialog stays closed; render `IABConsentDialog` as
described in [IAB TCF](/docs/frameworks/tanstack-start/iab). Provider options
such as `preloadDialog` go through `ConsentRoot`'s `options` prop.
