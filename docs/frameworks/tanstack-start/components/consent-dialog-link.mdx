## Reopen preferences from your footer

`ConsentDialogLink` is an unstyled button that opens the preference dialog.
Put it where your site keeps its legal links so preferences stay reachable
after the banner closes. The
[quickstart](/docs/frameworks/tanstack-start/quickstart#resolve-consent-in-the-root-route)
renders one in the root route's footer.

{/* example: fragment */}

```tsx title="src/components/site-footer.tsx"
import { ConsentDialogLink } from 'c15t/tanstack-start';

export function SiteFooter() {
  return (
    <footer>
      <a href="/privacy">Privacy policy</a>
      <ConsentDialogLink className="footer-link">Privacy settings</ConsentDialogLink>
    </footer>
  );
}
```

Render the footer inside `ConsentRoot`, with `ConsentDialog` mounted. It
renders a `button`; pass `asChild` to render your own link element instead.

`c15t/tanstack-start/components/consent-dialog-link` exports `ConsentDialogLink`
and nothing else. Import from that path when a module needs only the link, so
it does not load the rest of the adapter.
