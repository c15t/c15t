## Embed the preference center in a page

`ConsentWidget` renders the category switches and the Reject All, Accept All
and Save Settings actions in the page flow instead of a modal. Use it on a privacy or
settings route. Keep `ConsentDialog` in the root route too, so the banner's
Customize button still has a dialog to open.

{/* example: fragment */}

```tsx title="src/routes/privacy.tsx"
import { createFileRoute } from '@tanstack/react-router';
import { ConsentWidget } from 'c15t/tanstack-start';

const PrivacyPage = () => (
	<main>
		<h1>Privacy</h1>
		<section aria-labelledby="cookie-preferences">
			<h2 id="cookie-preferences">Cookie preferences</h2>
			<ConsentWidget />
		</section>
	</main>
);

export const Route = createFileRoute('/privacy')({ component: PrivacyPage });
```

The widget uses `ConsentRoot`'s policy, translations and backend. It needs no
second provider. `useConsentDraft` and `ConsentDraftProvider` also import from
`c15t/tanstack-start`.
