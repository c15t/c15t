## Install the right package

Most frameworks use one package, `c15t`, and import the framework entry point:
`c15t/next`, `c15t/react`, `c15t/vue`, `c15t/astro` or `c15t/tanstack-start`.
You do not need `@c15t/nextjs` or `@c15t/react` as well; `c15t` depends on
them.

Three frameworks use their own package: Svelte and SvelteKit use
`@c15t/svelte`, plain HTML uses `@c15t/browser`, and React Native uses
`@c15t/react-native`. Vendor script helpers are a separate install,
`@c15t/scripts`, in every framework.

v3 is published under the `alpha` tag. Install `c15t@alpha`; a plain
`c15t` install still gets v2.

## After the quickstart

A banner on screen does not mean analytics wait for consent. Move existing
scripts into c15t, replace embeds that load on their own, and keep a link to
reopen preferences. Then [verify the integration](/docs/guides/verify-consent).
