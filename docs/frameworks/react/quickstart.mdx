## Connect Inth

[Create an Inth project](https://inth.com), configure policy rules and the app's
allowed origin, and copy its backend endpoint. This guide uses a client-rendered
React app with Vite. Applications with a framework server should use that
framework's adapter for request prefetch.

<CommandTabs command="c15t" mode="install" />

Set `VITE_C15T_BACKEND_URL` to the endpoint from Inth. Vite embeds public values
at build time, so rebuild when changing it. Keep management credentials out of
public variables.

## Mount the provider and UI

```tsx title="src/consent.tsx"
import type { ReactNode } from 'react';
import {
  ConsentBanner,
  ConsentDialog,
  ConsentDialogLink,
  ConsentProvider,
  hosted,
} from 'c15t/react';
import 'c15t/react/styles.css';

const backendURL = import.meta.env.VITE_C15T_BACKEND_URL;
if (!backendURL) throw new Error('Set VITE_C15T_BACKEND_URL');
const mode = hosted({ url: backendURL });

export function Consent({ children }: { children: ReactNode }) {
  return (
    <ConsentProvider options={{ mode }}>
      {children}
      <ConsentBanner />
      <ConsentDialog />
      <footer><ConsentDialogLink>Privacy settings</ConsentDialogLink></footer>
    </ConsentProvider>
  );
}
```

```tsx title="src/main.tsx"
import { createRoot } from 'react-dom/client';
import App from './App';
import { Consent } from './consent';

const root = document.getElementById('root');
if (!root) throw new Error('Missing #root element');
createRoot(root).render(<Consent><App /></Consent>);
```

Keep `Consent` mounted across navigation. The banner appears when the resolved
policy requires a prompt; not every region or returning visitor needs one.
The dialog link keeps preferences reachable after the prompt closes.

## Gate optional functionality

```tsx
import { useConsent } from 'c15t/react';

export function MarketingContent() {
  return useConsent('marketing') ? <div>Optional marketing content</div> : null;
}
```

This controls the rendered component. Move vendor SDKs into the
[script loader](/docs/frameworks/react/script-loader) too. An independently
loaded analytics script does not wait merely because a consent provider exists.

`useConsent` returns effective permission, not proof of an explicit grant.
Read [consent state](/docs/guides/consent-state) when recording choice events.

## Verify and customize

Reject under an opt-in policy, reload and confirm optional requests stay blocked.
Reopen preferences, save a different choice and test navigation. Follow
[verification](/docs/guides/verify-consent), then
[customization](/docs/customization/overview) to apply your design.
