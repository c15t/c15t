## Load an external stylesheet

With Tailwind CSS 3, or when you want to put c15t in a named cascade layer,
import `c15t/react/styles.css` and then `c15t/react/iab/styles.css` at your
global stylesheet entry. The IAB stylesheet holds the IAB rules and uses the
base stylesheet's tokens. Set `styles: false` so the components use those
stylesheets:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
import 'c15t/react/styles.css';
import 'c15t/react/iab/styles.css';

// In the ConsentProvider options:
styles: false,
```

Tailwind CSS 3 also needs the
[PostCSS plugin](/docs/customization/tailwind#set-up-tailwind-css-3).
