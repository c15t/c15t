## Declare the vendors

Declare the vendors next to the scripts in `src/scripts.ts`, using the `vendor`
slug each script already carries:

{/* example: fragment */}

```ts title="src/scripts.ts (partial)"
import type { Vendor } from 'c15t';

export const vendors: Vendor[] = [
  {
    id: 'x-pixel',
    name: 'X Pixel',
    category: 'marketing',
    privacyPolicyUrl: 'https://x.com/privacy',
  },
];
```

Then add them to the provider options in `src/consent.tsx`:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
import { scripts, vendors } from './scripts';

<ConsentProvider options={{ mode, scripts, vendors }}>
```

`vendors` is a live option, like `scripts`: passing a new list replaces the
declared vendors. A provider that borrows a `runtime` does not accept
`vendors`; declare them in `createConsentRuntime({ vendors })` instead.

`ConsentGate` checks a category only. To render a component only while one
vendor is allowed, read `useVendorAllowed('youtube')` and render it when the
hook returns `true`. [Embeds](/docs/frameworks/react/embeds) covers the iframe
blocker's `data-vendor` attribute.

## What the preference dialog shows

`ConsentDialog` and `ConsentWidget` list each declared vendor under its
category, with its own switch.

## Build your own vendor switch

`useVendorDraft()` from `c15t/react` reads and stages vendor switches on the
same draft the category switches use, so one save records both.
`useVendorAllowed(id)` returns whether a vendor may run now: its category is
allowed and the visitor has not switched it off.

{/* example: fragment */}

```tsx title="src/x-pixel-switch.tsx (partial)"
import { useVendorAllowed, useVendorDraft } from 'c15t/react';

const { vendors, setVendor, save } = useVendorDraft();
const xPixelAllowed = useVendorAllowed('x-pixel');

<input
  type="checkbox"
  checked={vendors['x-pixel'] ?? true}
  onChange={(event) => setVendor('x-pixel', event.target.checked)}
/>
<button type="button" onClick={() => save()}>Save</button>
```

`save()` resolves `{ ok: false }` without recording anything when the policy
or the vendor list changed under the edit. Call `reset()` to start again.
`useDeclaredVendors()` returns the declared vendors, and `useVendorChoice()`
returns the recorded vendor decision, or `null` before the visitor made one.
