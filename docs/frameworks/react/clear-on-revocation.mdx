## Configure cleanup

Gating stops new requests, but it leaves the cookies and storage keys a vendor
already wrote. List the ones each optional category owns and add them to the
provider options in `src/consent.tsx`. When that category is denied, c15t
deletes them:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
import type { ClearOnRevocationConfig } from 'c15t';

const clearOnRevocation: ClearOnRevocationConfig = {
  measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
  marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
};

<ConsentProvider options={{ mode, scripts, clearOnRevocation }}>
```

The provider reads `clearOnRevocation` once, when it mounts; remount it to
change the list. A provider that borrows a `runtime` does not read it.
Configure cleanup on the runtime owner instead, with
`createConsentRuntime({ clearOnRevocation })`.
