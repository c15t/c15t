---
title: Callbacks
description: Observe explicit choices separately from effective permission changes.
group: frameworks
---

```tsx
import { ConsentProvider, offline } from '@c15t/react';

<ConsentProvider
  options={{
    mode: offline(),
    callbacks: {
      onChoiceRecorded: ({ snapshot, confirmed, actionAt }) => {
        console.log(snapshot.explicitChoice, confirmed, actionAt);
      },
      onPermissionsChanged: ({ snapshot, previous }) => {
        console.log(previous, snapshot.effectivePermissions);
      },
    },
  }}
>
  {children}
</ConsentProvider>
```

`onChoiceRecorded` runs after an explicit accept, reject, or save records at least one category. An empty save does nothing. Reconfirming an unchanged value records a new receipt for that category and invokes this callback once. `confirmed` contains only the categories confirmed by that action, and `actionAt` is their actual confirmation time.

`onPermissionsChanged` runs only when the kernel emits its distinct permissions event. Hydration, expiry, a policy change, or a privacy signal can change permissions without creating a choice. Registering a callback does not replay it.

Dismissing a notice invokes neither choice callback nor consent-saving endpoint. A detected Global Privacy Control signal can create a separate privacy directive, but never an explicit category choice. A saved `true` receipt can remain in `explicitChoice` while `effectivePermissions` is `false`.

## Migration

Replace `onConsentSet` with `onChoiceRecorded` when recording user decisions. Replace `onConsentChanged` with `onPermissionsChanged` when synchronizing gates or analytics permissions. Use `snapshot.effectivePermissions` for processing decisions and `snapshot.explicitChoice` for confirmation receipts. Do not build receipt timestamps from callback registration or component mounting.

`onBannerFetched` and `reloadOnConsentRevoked` are no longer provider options. Read initialization through `usePolicyResolution` and apply reload behavior explicitly from `onPermissionsChanged` if your application needs it.
