## When to compose

<import src="../../shared/react/compose.mdx#when-to-compose" />

For a banner that shares nothing with the stock markup, use the
[headless hooks](/docs/frameworks/react/headless). For one changed class,
token or prop, see [customize](/docs/frameworks/react/customize).

## Compose the banner

`CookieBanner` keeps the stock card, title and copy, and renders each action
the policy asks for as your design system's button. `BrandButton` stands in
for that button:

<include src="../../shared/examples/storybook-react/compose-button.mdx" />

<include src="../../shared/examples/storybook-react/compose-banner.mdx" />

The parts read the nearest `ConsentProvider`. In the `src/consent.tsx` file
from the [quickstart](/docs/frameworks/react/quickstart), import
`CookieBanner` from `./cookie-banner` and render it in place of
`ConsentBanner`, next to `ConsentDialog`:

{/* example: fragment */}

```tsx title="src/consent.tsx (partial)"
<ConsentProvider options={{ mode, scripts }}>
	{children}
	<CookieBanner />
	<ConsentDialog />
	<footer>
		<ConsentDialogLink>Privacy settings</ConsentDialogLink>
	</footer>
</ConsentProvider>;
```
