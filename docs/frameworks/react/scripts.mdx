## Register vendor scripts

Pass vendor loaders to `ConsentProvider` through `options.scripts`. The
provider loads each script when its category is allowed and removes it when
the category is denied. The [quickstart](/docs/frameworks/react/quickstart)
registers PostHog and X Pixel this way:

Each helper from `@c15t/scripts` sets its own category and a stable `id`.
Remove every other loader for the same vendor, such as a `<script>` tag in
`index.html` or an SDK you initialize at module level, so the vendor loads
once and only through c15t. [Integrations](/docs/integrations/overview) lists
every helper, and [building integrations](/docs/integrations/building-integrations)
covers a vendor without one.

## What happens when consent changes

- **Allowed.** The script loads, or its SDK is started, the first time its
  category is allowed.
- **Denied later.** The provider removes the script element. Code that already
  ran keeps running, so after the visitor turns off a category they had
  allowed, the provider reloads the page once the save finishes. Set
  `reloadOnConsentRevoked: false` only if every gated vendor stops itself.
- **`alwaysLoad` helpers.** Some integrations, such as Google Consent Mode,
  load before consent and pass the visitor's choice to the vendor. Read the
  vendor's guide; a category on a script does not always mean zero requests.

## Gate an iframe or widget

Wrap embeds in `ConsentGate`. It renders its children only while the category
is allowed and shows a placeholder otherwise:

{/* example: fragment */}

```tsx title="src/product-video.tsx"
import { ConsentGate } from 'c15t/react';

export function ProductVideo() {
  return (
    <ConsentGate category="marketing">
      <iframe
        src="https://www.youtube-nocookie.com/embed/VIDEO_ID"
        title="Product tour"
        allowFullScreen
      />
    </ConsentGate>
  );
}
```

Replace `VIDEO_ID` with your video. The iframe is absent from the page until
the visitor allows `marketing`, and it is removed if they revoke it.
[ConsentGate](/docs/frameworks/react/components/consent-gate) documents the
placeholder and its props. For iframes rendered outside React, such as CMS
content, give the iframe `data-category` and `data-src` instead of `src`; the
provider's iframe blocker sets `src` once the category is allowed.

## Block requests an SDK sends itself

Some SDKs are already on the page and send beacons or API calls of their own.
Add `networkBlocker` rules to the provider options to stop `fetch` and
`XMLHttpRequest` calls to those domains until the category is allowed. This
partial example adds the option next to the existing `mode` and `scripts`:

{/* example: fragment */}

```tsx title="src/consent.tsx"
const networkBlocker = {
  rules: [
    { id: 'google-analytics', domain: 'google-analytics.com', category: 'measurement' },
    { id: 'meta-pixel', domain: 'facebook.com', pathIncludes: '/tr', category: 'marketing' },
  ],
};

<ConsentProvider options={{ mode, scripts, networkBlocker }}>
```

## Clear stored data after revocation

Removing a script does not delete the cookies or storage entries it wrote. Add
`clearOnRevocation` to the provider options to delete the entries you list for
each category when it is denied. The option is read once, when the provider
mounts. [Clear on revocation](/docs/integrations/clear-on-revocation) covers
configuration and browser limits.

## Vendors with their own switch

To let a visitor allow a category but turn off one vendor, pass `vendors` to
the provider options. The preference dialog then lists each vendor under its
category. [Granular consent](/docs/integrations/granular-consent) explains the
setup. To keep another consent tool in charge, see
[use c15t with an existing CMP](/docs/integrations/existing-cmp). To send your
own events only to allowed integrations, see
[send events only to allowed integrations](/docs/integrations/overview#send-events-only-to-allowed-integrations).

## Check the scripts

Open DevTools Network in a private window, filter by each vendor's domain and
reload.

1. Before a choice under an opt-in policy, no vendor script, iframe or blocked
   domain appears. With `networkBlocker`, the console logs each blocked request.
2. Allow one category. Only that category's vendors load.
3. Turn the category off. The page reloads and the vendor stays absent.
4. Reload again. The rejection holds.

[Verify consent](/docs/guides/verify-consent) has the full checklist.
