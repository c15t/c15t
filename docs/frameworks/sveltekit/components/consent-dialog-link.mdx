## Reopen preferences from your footer

`ConsentDialogLink` is an unstyled button that opens the preference dialog.
Put it in the root layout's footer, so it is on every page:

<include src="../../../shared/examples/sveltekit-demo/layout.mdx" />

It needs `ConsentDialog` mounted in the same provider. With a server
`prefetch`, the link is in the server HTML. Without one, such as on a
prerendered page, it appears after hydration once the policy resolves.
