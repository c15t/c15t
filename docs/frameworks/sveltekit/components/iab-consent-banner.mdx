## IAB banner in the server HTML

With a server-resolved IAB policy in `prefetch`, `IABConsentBanner` renders
into the server HTML. The browser then fetches the Global Vendor List from the
route the server names. [IAB TCF](../iab#iab-on-the-server) covers the server
side.
