## Render the dialog

Render `ConsentDialog` once, in the root layout inside
`ConsentRoot`. The banner's Customize button and
`ConsentDialogLink` open it:

`ConsentDialog` is never in the server HTML. It loads in the browser after
hydration, before anyone opens it, so a server-rendered page does not carry
its markup or script.
