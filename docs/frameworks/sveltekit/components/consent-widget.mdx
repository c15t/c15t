## Widget in the server HTML

With server-resolved consent from the root layout, the widget renders into the
route's HTML with the visitor's stored choices. Without one, it appears after
hydration once the policy resolves. The page title in the example is
`src/routes/privacy/+page.svelte`; any route under the root layout works.
