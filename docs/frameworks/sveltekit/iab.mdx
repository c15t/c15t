## IAB on the server

`loadConsent` and the manifest route handlers know about IAB policies. With a
server-resolved IAB policy, the IAB banner can render in the server HTML, and
the browser fetches the Global Vendor List from the route the server names.
Pass `fetchGvl` to `createSvelteKitConsentRouteHandlers` to change how the
manifest route fetches the vendor list.
