## Server requests are not blocked

The network blocker runs in the browser. A `fetch` in a SvelteKit `load`,
`+server.ts` or `hooks.server.ts` is never blocked, even when the visitor has
denied the category. If server code sends data to a vendor, check the
visitor's stored choice yourself before it does; `event.locals.c15t.config`
from [`c15tHandle`](./server-api#c15thandle) holds it.
