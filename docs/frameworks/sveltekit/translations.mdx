## Language on the server

`loadConsent` resolves the language from the request's `Accept-Language`
header and returns the backend's copy for it in `prefetch`, so the server HTML
is already in the visitor's language. Pass `language` to `loadConsent` or
`c15tHandle` to force one, for example from a `/de/` route prefix. The
provider applies its `i18n` messages for that language over the prefetched
copy, so the server HTML already shows your overrides.
