## Configure cleanup

Gating stops new requests, but it leaves the cookies and storage keys a vendor
already wrote. List the ones each optional category owns in
`c15t.config.ts`. When that category is denied, c15t deletes them:

{/* example: fragment */}

```ts title="c15t.config.ts"
import { defineConsentConfig } from 'c15t/next';

export default defineConsentConfig({
	clearOnRevocation: {
		measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
		marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
	},
});
```

`clearOnRevocation` is a top-level option, not inside `options`. Keep your
`scripts` in the same call. A `clearOnRevocation` prop on `ConsentRoot` wins
over the config's. It is read once, when `ConsentRoot` mounts; remount it to
change the list.
