## Start with your router

Most Next.js apps use the App Router with a Next.js server. Follow the
[App Router guide](/docs/frameworks/next/app-router). It takes about six files:
a shared config, a manifest route, a script list, a client wrapper, a root
layout and your global stylesheet.

| Your app | Guide |
| --- | --- |
| App Router with a Next.js server | [App Router](/docs/frameworks/next/app-router) |
| Pages Router with a Next.js server | [Pages Router](/docs/frameworks/next/pages-router) |
| `output: 'export'`, with either router | [Static export](/docs/frameworks/next/static-export) |
| Static, ISR or `'use cache'` pages, Cache Components, or the banner in the first HTML | [Rendering and deployment](/docs/frameworks/next/rendering) |
| The fewest files, with consent resolved in the browser | [Client-side initialization](/docs/frameworks/next/client-side) |

Every guide uses [Inth](https://inth.com) for policies and consent records.
Create a project, set its policy rules, add your site's origin to its trusted
origins, and copy its backend URL before you start. The guides install
`c15t` and `@c15t/integrations`:

<CommandTabs command="c15t@alpha @c15t/integrations@alpha" mode="install" />

## What the guides set up

With a Next.js server, your server caches the project's public policy manifest
and resolves consent for each visitor. The browser gets the answer with the
page and makes no `/init` request. Consent choices go to Inth. PostHog and
X Pixel wait for consent, a YouTube embed stays blocked until measurement is
allowed, and a footer link reopens preferences.

A [self-hosted backend](/docs/self-host/quickstart) uses the same files with its
own URL. [Offline mode](/docs/frameworks/next/data-fetching-reference#offline-configuration)
keeps policy in your code and choices in the browser, with no consent records.
Not recommended for production environments.

The [runnable Next.js example](/docs/examples) contains every file the guides
show, with routes for each layout. After setup,
[verify requests and persistence](/docs/guides/verify-consent). A visible banner
alone does not prove that analytics wait for consent.
