## When to go headless

<import src="../../shared/react/headless.mdx#when-to-go-headless" />

Check for a policy before rendering your own surfaces. `useModel()` from
`c15t/next` returns `null` while no rule has resolved and `'none'` under a rule
that owes no consent UI, and the pre-built surfaces render nothing in that
state.

## Minimal example

The headless hooks read the runtime from the `ConsentRoot` set up in your
[App Router](/docs/frameworks/next/app-router) or
[Pages Router](/docs/frameworks/next/pages-router) guide, so they only run in a
Client Component. Render this component inside that existing root in place
of the stock banner. Keep the dialog and persistent preferences control.

```tsx title="components/consent-banner.tsx"
'use client';

import {
	StreamedConsentSurface,
	useBannerCopy,
	useConsentLabels,
	useHeadlessConsentUI,
} from 'c15t/next/headless';

function BannerContent() {
	const { banner, performAction, openDialog } = useHeadlessConsentUI();
	const { title, description } = useBannerCopy();
	const labels = useConsentLabels();

	if (!banner.isVisible) {
		return null;
	}

	return (
		<section role="region" aria-label={title}>
			<h2>{title}</h2>
			<p>{description}</p>
			{banner.preferenceControls.map((right) => (
				<button key={right} type="button" onClick={openDialog}>
					{labels.preferenceControls[right]}
				</button>
			))}
			{banner.actionGroups.map((group) => (
				<div key={group.join('-')}>
					{group.map((action) => (
						<button
							key={action}
							type="button"
							data-primary={banner.primaryActions.includes(action) || undefined}
							onClick={() => performAction(action)}
						>
							{labels.actions[action]}
						</button>
					))}
				</div>
			))}
		</section>
	);
}

export function Banner() {
	return (
		<StreamedConsentSurface>
			<BannerContent />
		</StreamedConsentSurface>
	);
}
```

With the [streamed layout](/docs/frameworks/next/rendering#stream-or-await-consent-in-the-app-router),
`ConsentRoot` gets a pending promise. `StreamedConsentSurface` waits for it in
its own `Suspense` boundary, so your banner follows in a later chunk of the
same response and shows before hydration, like the stock one. Call the hooks
in a component inside it. Hooks called above it read the state from before
consent resolved, which has no banner. Without the surface, the banner shows
after hydration. With an awaited layout, the surface renders its children as
they are.
