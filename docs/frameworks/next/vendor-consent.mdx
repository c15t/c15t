## Declare the vendors

Built-in `@c15t/integrations` helpers already list their vendor by name, so
you only declare a vendor for a script of your own, or to replace a helper's
name and privacy policy.

Declare the vendors next to the scripts in `c15t.config.ts`, using the
`vendor` slug each script already carries:

{/* example: fragment */}

```ts title="c15t.config.ts"
import { defineConsentConfig } from 'c15t/next';

export default defineConsentConfig({
	vendors: [
		{
			id: 'x-pixel',
			name: 'X Pixel',
			category: 'marketing',
			privacyPolicyUrl: 'https://x.com/privacy',
		},
	],
});
```

`vendors` is a top-level option, not inside `options`. Keep your `scripts` in
the same call. A `vendors` prop on `ConsentRoot` wins over the config's.

`ConsentGate` checks a category only. To render a component only while one
vendor is allowed, read `useVendorAllowed('youtube')` and render it when the
hook returns `true`. [Embeds](/docs/frameworks/next/embeds) covers the iframe
blocker's `data-vendor` attribute.

## What the preference dialog shows

`ConsentDialog` and `ConsentWidget` list each declared vendor under its
category, with its own switch.

## Build your own vendor switch

`useVendorDraft()` from `c15t/next` reads and stages vendor switches on the
same draft the category switches use, so one save records both.
`useVendorAllowed(id)` returns whether a vendor may run now: it is declared,
its category is allowed and the visitor has not switched it off.

{/* example: fragment */}

```tsx title="components/x-pixel-switch.tsx (partial)"
'use client';

import { useVendorAllowed, useVendorDraft } from 'c15t/next';

const { vendors, setVendor, save } = useVendorDraft();
const xPixelAllowed = useVendorAllowed('x-pixel');

<input
  type="checkbox"
  checked={vendors['x-pixel'] ?? true}
  onChange={(event) => setVendor('x-pixel', event.target.checked)}
/>
<button type="button" onClick={() => save()}>Save</button>
```

`save()` resolves `{ ok: false }` without recording anything when the policy
or the vendor list changed under the edit. Call `reset()` to start again.
`useDeclaredVendors()` returns the declared vendors, and `useVendorChoice()`
returns the recorded vendor decision, or `null` before the visitor made one.
