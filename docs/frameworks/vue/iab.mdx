## Turn on IAB TCF

IAB TCF is a policy setting, not a Vue option. When the visitor's policy uses
the `iab` model and names your CMP ID, `ConsentRoot` renders the IAB banner and
preference centre in place of the standard ones. No extra component or
stylesheet is needed; the IAB components include their own styles. Configure
the CMP ID and vendors in your Inth project, or see
[IAB TCF for a self-hosted backend](/docs/self-host/guides/iab-tcf). Publisher
restrictions are set in your app; see
[restrict how vendors use a purpose](#restrict-how-vendors-use-a-purpose).

To compose the IAB surfaces yourself, import
[`IABConsentBanner`](/docs/frameworks/vue/components/iab-consent-banner) and
[`IABConsentDialog`](/docs/frameworks/vue/components/iab-consent-dialog) and
render them in place of `ConsentRoot`. For a custom preference centre, `useConsentIabSelection()`
reads the visitor's purpose and vendor selection and `useConsentIabSave()`
writes it and the TC String.

## Restrict how vendors use a purpose

Publisher restrictions override a vendor's declared use of one purpose. Set
them under the plugin's `iab` option. The vendor IDs below are placeholders;
use vendors from your list whose declarations allow each restriction.

{/* example: fragment */}

```ts title="src/main.ts (partial)"
app.use(c15tVue, {
	backendURL: 'https://your-project.inth.app',
	iab: {
		publisherRestrictions: [
			// Vendors 10 and 755 may not use purpose 4.
			{ purposeId: 4, restrictionType: 0, vendorIds: [10, 755] },
			// Vendor 755 must use legitimate interest for purpose 7.
			{ purposeId: 7, restrictionType: 2, vendorIds: [755] },
		],
	},
});
```

`iab` also takes `publisherCountryCode`, a `vendors` allowlist,
`customVendors` and `cmpVersion`. Fields you leave out come from the policy:
the CMP ID, custom vendors and vendor list arrive with `/init`. The CMP still
mounts only while the visitor's policy uses the `iab` model. `iab: false`
mounts no CMP.

## Vendor list loading

The browser receives a reference to the Global Vendor List with the policy.
The IAB module fetches the full list as soon as it mounts, before the visitor
clicks, and waits for it before it writes a TC String. A failed fetch leaves
the banner visible and grants nothing. Allow the list's origin, usually your
backend, in your CSP `connect-src`. See
[Content Security Policy](/docs/frameworks/vue/content-security-policy).

## Verify IAB consent

Load the app under your IAB policy and confirm the IAB banner appears. In the
browser console, `__tcfapi('getTCData', 2, console.log)` returns a TC String
after you accept or reject.
