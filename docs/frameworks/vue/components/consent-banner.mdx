## Usage

`ConsentRoot` already renders `ConsentBanner`. Import the banner yourself
only when you compose the surfaces, for example to set its variant in the
template or to render it without `ConsentRoot`. Import it from
`c15t/vue/runtime/components/consent-banner.vue`:

<include src="../../../shared/examples/vue/consent-surfaces.mdx" />

Render this component in your root component in place of `ConsentRoot`.
Render `ConsentManager` with it, or Customize opens nothing. A statically
imported `ConsentManager` is part of your main bundle, while `ConsentRoot`
loads the dialog as a separate chunk. Unlike `ConsentRoot`, these components
do not switch to the IAB surfaces under an IAB policy. The c15tVue plugin
still adds the `tokens` option to the page.

<import src="../../../shared/vue/components/consent-banner.mdx#behavior" />

<import src="../../../shared/vue/components/consent-banner.mdx#props" />

To set the variant for every banner without importing the component, use
`presentation.prompt` in the plugin options. See
[customize](/docs/frameworks/vue/customize#change-the-banner-layout).
