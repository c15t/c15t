## Import the dialog when you compose surfaces

`ConsentRoot` already renders `ConsentManager` when preferences open. Import
it yourself only when you compose the surfaces in place of `ConsentRoot`.
Import it from `c15t/vue/vue-plugin`:

<include src="../../../shared/examples/vue/consent-surfaces.mdx" />

## Open the dialog from your code

Set `activeUI` to `'manager'` with `useConsentActiveUI()` from
`c15t/vue/vue-plugin`. The Vue adapter uses `'manager'` where the React
adapter uses `'dialog'`.

{/* example: fragment */}

```ts
const activeUI = useConsentActiveUI();
activeUI.value = 'manager';
```

For a footer link, use
[ConsentDialogLink](/docs/frameworks/vue/components/consent-dialog-link),
which hides itself when the policy offers no preferences.
