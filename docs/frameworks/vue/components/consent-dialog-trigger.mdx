## Usage

Turn the trigger on with `showTrigger` in the plugin options. `ConsentRoot`
then renders it:

{/* example: fragment */}

```ts title="src/main.ts"
app.use(c15tVue, {
  backendURL,
  scripts,
  showTrigger: true,
  triggerDefaultPosition: 'bottom-left',
});
```

When you compose the surfaces without `ConsentRoot`, import the trigger from
`c15t/vue/runtime/components/consent-dialog-trigger.vue` and render it
yourself:
