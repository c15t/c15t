## Import the IAB banner in place of `ConsentRoot`

`ConsentRoot` renders `IABConsentBanner` for you when the visitor's policy
uses IAB TCF. Import it only when every policy on your site is IAB and you
compose the surfaces yourself. Import it from
`c15t/vue/runtime/components/iab-consent-banner.vue`:

<include src="../../../shared/examples/vue/iab-surfaces.mdx" />

Render this in place of `ConsentRoot`. A visitor whose policy is not IAB sees
nothing from these components.
