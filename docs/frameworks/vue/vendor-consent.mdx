## Declare the vendors

Declare the vendors next to the scripts in `src/scripts.ts`, using the `vendor`
slug each script already carries:

{/* example: fragment */}

```ts title="src/scripts.ts (partial)"
import type { Vendor } from 'c15t';

export const vendors: Vendor[] = [
	{
		id: 'x-pixel',
		name: 'X Pixel',
		category: 'marketing',
		privacyPolicyUrl: 'https://x.com/privacy',
	},
];
```

Then pass them to the plugin in `src/main.ts`:

{/* example: fragment */}

```ts title="src/main.ts (partial)"
import { scripts, vendors } from './scripts';

createApp(App)
	.use(c15tVue, {
		backendURL: 'https://your-project.inth.app',
		scripts,
		vendors,
	})
	.mount('#app');
```

## What the preference dialog shows

`ConsentManager`, which `ConsentRoot` renders, and `ConsentWidget` list each
declared vendor under its category, with its own switch.

## Build your own vendor switch

`useConsentDraft()` from `c15t/vue/vue-plugin` holds the category and vendor
switches of a preference form. `vendors` has one value per declared vendor,
`setVendor(id, granted)` changes one, and `save()` records the categories and
the vendors that changed:

{/* example: fragment */}

```vue title="src/components/x-pixel-switch.vue (partial)"
<script setup lang="ts">
import { useConsentDraft } from 'c15t/vue/vue-plugin';

const { vendors, setVendor, save } = useConsentDraft();
</script>

<template>
	<input
		type="checkbox"
		:checked="vendors['x-pixel'] ?? true"
		@change="setVendor('x-pixel', ($event.target as HTMLInputElement).checked)"
	/>
	<button type="button" @click="save()">Save</button>
</template>
```

`save()` resolves `{ ok: false }` without recording anything while `isStale`
is `true`. [Composables](/docs/frameworks/vue/composables) covers the draft.

## Check whether a vendor may run

`useVendorAllowed(id)` from `c15t/vue/vue-plugin` returns a computed that is
`true` while the vendor may run: it is declared, its category is allowed and
the visitor has not switched it off.

{/* example: fragment */}

```vue title="src/components/x-pixel-status.vue (partial)"
<script setup lang="ts">
import { useVendorAllowed } from 'c15t/vue/vue-plugin';

const xPixelAllowed = useVendorAllowed('x-pixel');
</script>
```
