## What GPP does

The `gpp` option installs `window.__gpp`, the GPP 1.1 CMP API, and keeps its
GPP string in step with the visitor's choices. Prebid.js, Google Ad Manager
and other ad tech read US privacy signals from it.

## Turn on GPP

Pass `gpp` to the Vue plugin in `src/main.ts`:

{/* example: fragment */}

```ts title="src/main.ts"
import { c15tVue, manifest } from 'c15t/vue/vue-plugin';
import { createApp } from 'vue';

import App from './App.vue';

createApp(App)
	.use(c15tVue, {
		// Loads @c15t/iab/gpp and installs `__gpp` once the app mounts.
		gpp: true,
		mode: manifest(),
	})
	.mount('#app');
```

The plugin loads `@c15t/iab/gpp` when the app mounts, so apps without `gpp`
never download it. The Vue integration already depends on `@c15t/iab`;
nothing else to install. Unmounting the app removes `__gpp`.

Replace `https://your-project.inth.app` with your project's backend URL. The
GPP string follows the policy and location Inth resolves for the visitor, so
a US visitor's state comes from the backend.

If you pass the plugin a `runtime` created with `createConsentRuntime()`, the
plugin ignores `gpp`. Set `gpp` and `loadGPP: () => import('@c15t/iab/gpp')`
on that runtime instead.

To add the TCF EU section for visitors under an `iab` policy, set up
[IAB TCF](/docs/frameworks/vue/iab) as well.
