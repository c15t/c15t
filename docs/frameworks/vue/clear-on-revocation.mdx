## Configure cleanup

Gating stops new requests, but it leaves the cookies and storage keys a vendor
already wrote. List the ones each optional category owns and pass them to the
plugin in `src/main.ts`. When that category is denied, c15t deletes them:

{/* example: fragment */}

```ts title="src/main.ts (partial)"
createApp(App)
	.use(c15tVue, {
		backendURL: 'https://your-project.inth.app',
		scripts,
		clearOnRevocation: {
			measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
			marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
		},
	})
	.mount('#app');
```

The plugin reads `clearOnRevocation` once, when the app mounts.
