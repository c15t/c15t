## Where the text comes from

The banner, dialog and IAB text comes from the translations in your Inth
project, or your self-hosted backend's configuration. The policy carries the
text for the visitor's language. Edit copy there, not in your Nuxt code. The
module has no option for message overrides.

[Copy and translations](/docs/customization/translations) lists the message
keys and how to write labels that describe each action.

## How c15t picks the language

The request's `Accept-Language` header decides:

- With `manifest: 'server'`, the Nuxt server reads the header during server
  rendering and resolves the text from the cached manifest. The banner is in
  the visitor's language in the first HTML.
- With `manifest` unset, the server forwards the header to the backend's
  `/init`.
- With `manifest: 'client'`, the browser reads `navigator.language` and
  resolves the text from the manifest.

On prerendered and cached routes the browser requests `/api/c15t/init` after
hydration, and that request carries the browser's own header. When your
project has no text for the language, the backend picks its fallback
language.

The text direction follows the resolved language. Right-to-left languages
render the banner and dialog with `dir="rtl"`, and a default corner position
mirrors.

## Text that does not come from translations

A few labels are fixed English strings in the components. Replace them in the
visitor's language when your site has more than one:

| Text | Where | How to change it |
| --- | --- | --- |
| "Privacy settings" | `ConsentPreferencesLink` | Pass the label in its default slot. |
| "Content requires permission." | `ConsentGate` without a placeholder | Pass a `placeholder` slot. |
| "Open privacy settings" | `ConsentDialogTrigger` label | Set the `triggerAriaLabel` option. |

## Verify

Request a page with `curl -H 'Accept-Language: de' <your-url>` under a policy
that asks for consent, and confirm the banner text in the HTML is German, if
your project translates German. Switch the language in the browser with your
switcher and confirm the banner and dialog text change without a reload.
