## Configure cleanup

Gating stops new requests, but it leaves the cookies and storage keys a vendor
already wrote. List the ones each optional category owns under the `c15t` key
in `nuxt.config.ts`. When that category is denied, c15t deletes them:

{/* example: fragment */}

```ts title="nuxt.config.ts (partial)"
export default defineNuxtConfig({
	c15t: {
		clearOnRevocation: {
			measurement: { cookies: ['_ga', '_ga_*'], localStorage: ['analytics:*'] },
			marketing: { cookies: ['_fbp'], sessionStorage: ['campaign-id'] },
		},
	},
});
```

`clearOnRevocation` is plain data, so it can go in `nuxt.config.ts` or in the
`c15t` key of `app/app.config.ts`. The module reads it once, in the browser,
after hydration.
