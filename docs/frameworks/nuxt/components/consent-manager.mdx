## Import the dialog when you compose surfaces

`ConsentRoot` already renders `ConsentManager` when preferences open. Import
it yourself only when you compose the surfaces in place of `ConsentRoot`. The
module does not register it globally, so import it from
`c15t/vue/runtime/components/consent-manager.vue`:

<include src="../../../shared/examples/nuxt/consent-surfaces.mdx" />

## Open the dialog from your code

Set `activeUI` to `'manager'` with the auto-imported `useConsentActiveUI()`.
The Vue components use `'manager'` where the React adapter uses `'dialog'`.

{/* example: fragment */}

```ts
const activeUI = useConsentActiveUI();
activeUI.value = 'manager';
```

For a footer link, use
[ConsentDialogLink](/docs/frameworks/nuxt/components/consent-dialog-link),
which hides itself when the policy offers no preferences.
