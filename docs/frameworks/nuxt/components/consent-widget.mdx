## Add the widget to your privacy page

The Nuxt module registers `ConsentWidget` globally. Render it on your privacy
or account settings page without an import:

<include src="../../../shared/examples/nuxt/privacy-page.mdx" />

Keep `ConsentRoot` in `app.vue` too, so visitors on other pages still get the
banner. With `manifest: 'server'`, the widget renders on the server with the
visitor's recorded choice already applied to the switches.
