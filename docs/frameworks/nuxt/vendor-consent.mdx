## Declare the vendors

Declare the vendors next to the scripts in `app/consent-scripts.ts`, using the
`vendor` slug each script already carries:

{/* example: fragment */}

```ts title="app/consent-scripts.ts (partial)"
import type { Vendor } from 'c15t';

export const vendors: Vendor[] = [
  {
    id: 'x-pixel',
    name: 'X Pixel',
    category: 'marketing',
    privacyPolicyUrl: 'https://x.com/privacy',
  },
];
```

Then register them under the `c15t` key in `app/app.config.ts`:

{/* example: fragment */}

```ts title="app/app.config.ts (partial)"
import { scripts, vendors } from './consent-scripts';

export default defineAppConfig({
  c15t: { scripts, vendors },
});
```

Vendors are plain data, so the `c15t` key in `nuxt.config.ts` accepts them too.
The module combines the arrays from both files.

`ConsentGate` checks a category only. For an iframe, add `data-vendor` and use
the iframe blocker; see [embeds](/docs/frameworks/nuxt/embeds).

## What the preference dialog shows

`ConsentManager`, which `ConsentRoot` renders, and `ConsentWidget` list each
declared vendor under its category, with its own switch.

## Build your own vendor switch

`useConsentDraft()`, which the module auto-imports, holds the category and vendor
switches of a preference form. `vendors` has one value per declared vendor,
`setVendor(id, granted)` changes one, and `save()` records the categories and
the vendors that changed:

{/* example: fragment */}

```vue title="app/components/x-pixel-switch.vue (partial)"
<script setup lang="ts">
const { vendors, setVendor, save } = useConsentDraft();
</script>

<template>
  <input
    type="checkbox"
    :checked="vendors['x-pixel'] ?? true"
    @change="setVendor('x-pixel', ($event.target as HTMLInputElement).checked)"
  />
  <button type="button" @click="save()">Save</button>
</template>
```

`save()` resolves `{ ok: false }` without recording anything while `isStale`
is `true`. [Composables](/docs/frameworks/nuxt/composables) covers the draft.

## Check whether a vendor may run

`useVendorAllowed(id)`, which the module auto-imports, returns a computed that
is `true` while the vendor may run: it is declared, its category is allowed
and the visitor has not switched it off.

{/* example: fragment */}

```vue title="app/components/x-pixel-status.vue (partial)"
<script setup lang="ts">
const xPixelAllowed = useVendorAllowed('x-pixel');
</script>
```
