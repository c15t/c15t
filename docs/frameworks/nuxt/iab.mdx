## Turn on IAB TCF

IAB TCF is off until you turn it on. Add `iab` under the `c15t` key in
`nuxt.config.ts`; an empty object is enough:

<include src="../../shared/examples/nuxt/iab-opt-in.mdx" />

With `iab` set, `ConsentRoot` renders the IAB banner and preference centre in
place of the standard ones while the visitor's policy uses the `iab` model and
names your CMP ID, and c15t installs `__tcfapi`. Configure the CMP ID and
vendors in your Inth project, or see
[IAB TCF for a self-hosted backend](/docs/self-host/guides/iab-tcf). No extra
component or stylesheet is needed; the IAB components include their own
styles.

Without `iab`, or with `iab: false` or `iab: { enabled: false }`, IAB stays
off: no `__tcfapi` is installed, the app never loads `@c15t/iab`, and pages do
not prefetch it.

If a visitor's policy uses the `iab` model and the backend sends its vendor
list while IAB is off, the app throws an `IABUnavailableError` (code
`C15T_IAB_UNAVAILABLE`). The standard banner does not handle the IAB model,
so the visitor would otherwise get no working consent UI. A server render
fails and Nuxt renders its error page with status 500. On a page the browser
resolves itself, such as a prerendered page or one with `ssr: false`, the
module shows the same error page from the browser. Set `iab`, or remove the
`iab` model from the policy. A backend that answers `gvl: null` turns IAB off
for the request, and the policy runs as opt-in. See
[troubleshooting](/docs/frameworks/nuxt/troubleshooting#the-page-throws-iabunavailableerror).

Set `iab` in `nuxt.config.ts` rather than only in `app.config.ts`. The build
reads the module options to decide whether pages prefetch the IAB banner and
CMP. IAB set only in `app.config.ts` still works, but the browser fetches those
files only once the policy calls for them, so the CMP is ready later and, on
`ssr: false` pages, the IAB banner appears later. `iab` is read once, when the
app starts; changing it with `updateAppConfig()` has no effect.

To compose the IAB surfaces yourself, import
[`IABConsentBanner`](/docs/frameworks/nuxt/components/iab-consent-banner) and
[`IABConsentDialog`](/docs/frameworks/nuxt/components/iab-consent-dialog) and
render them in place of `ConsentRoot`. For a custom preference centre, `useConsentIabSelection()`
reads the visitor's purpose and vendor selection and `useConsentIabSave()`
writes it and the TC String.

## Restrict how vendors use a purpose

Publisher restrictions override a vendor's declared use of one purpose. Set
them under the module's `iab` option. The vendor IDs below are placeholders;
use vendors from your list whose declarations allow each restriction.

{/* example: fragment */}

```ts title="nuxt.config.ts (partial)"
export default defineNuxtConfig({
	modules: ['c15t/vue'],
	c15t: {
		backendURL: 'https://your-project.inth.app',
		iab: {
			publisherRestrictions: [
				// Vendors 10 and 755 may not use purpose 4.
				{ purposeId: 4, restrictionType: 0, vendorIds: [10, 755] },
				// Vendor 755 must use legitimate interest for purpose 7.
				{ purposeId: 7, restrictionType: 2, vendorIds: [755] },
			],
		},
	},
});
```

`iab` also takes `publisherCountryCode`, a `vendors` allowlist,
`customVendors` and `cmpVersion`. Fields you leave out come from the policy:
the CMP ID, custom vendors and vendor list arrive with `/init`. The CMP mounts
only while the visitor's policy uses the `iab` model.

## Vendor list during server rendering

For an IAB policy, the server HTML carries the banner's purpose names, vendor
count and a reference to the Global Vendor List, not the whole list. The banner
renders on the server with the same summary the browser shows. After
hydration, the IAB module fetches the full list and loads it before it saves a
TC String. With `buildManifest: true` or `manifest: 'server'`, the module's
init route serves the versioned list with a one-day public cache. Allow that
route, or your backend origin, in your CSP `connect-src`. See
[Content Security Policy](/docs/frameworks/nuxt/content-security-policy).

## Verify IAB consent

Load a page under your IAB policy and confirm the IAB banner appears. In the
browser console, `__tcfapi('getTCData', 2, console.log)` returns a TC String
after you accept or reject. If Nuxt shows its error page with an
`IABUnavailableError` instead, `iab` is not set.
