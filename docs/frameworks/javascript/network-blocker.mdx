## Attach the blocker

```ts
import { createNetworkBlocker } from '@c15t/core/modules/network-blocker';

const blocker = createNetworkBlocker({
  kernel,
  rules: [
    {
      id: 'analytics',
      domain: 'analytics.example.com',
      category: 'measurement',
    },
  ],
});
```

Reuse the kernel from the [quickstart](/docs/frameworks/javascript/quickstart).
Install the module before the application starts requests it must control.
Requests match the configured rules and current effective permissions, including
expiry and privacy restrictions. Already-issued requests cannot be recalled.

Replace rules with `blocker.updateRules(nextRules)`. `blocker.setEnabled(false)`
disables interception; it does not record a choice. Dispose the blocker at teardown.
