## Connect Inth

[Create an Inth project](https://inth.com), set its policy rules, add your
app's origin to its trusted origins, and copy the project's backend URL. The
URL is public configuration.

This guide uses `@c15t/browser` as an ES module in a Vite app. `init()` starts
the consent runtime and mounts the stock banner and preference dialog. For
your own UI, use the [headless runtime](/docs/frameworks/javascript/headless)
instead. Sites without a build step load the same package from a script tag;
[choose your setup](/docs/concepts/choose-your-setup) points to that guide.

## Install

<CommandTabs command="@c15t/browser@alpha @c15t/integrations@alpha" mode="install" />

`@c15t/browser` is not part of the `c15t` package. `@c15t/scripts` supplies
the PostHog and X Pixel helpers used below.

## Set the backend URL

This setup reads Vite's public environment variables. Put the Inth URL and your
vendor IDs in `.env.local`:

```dotenv title=".env.local"
VITE_C15T_BACKEND_URL=https://your-project.inth.app
VITE_POSTHOG_KEY=
VITE_POSTHOG_HOST=
VITE_X_PIXEL_ID=
```

The vendor IDs are optional. An empty ID leaves that vendor out. When you
enable PostHog, set both its project key and the API host from your PostHog
project. Vite embeds these values at build time, so restart the dev server
after editing them and rebuild for deployment. Other bundlers have their own
way to expose public values.

## Register consent-gated scripts

Create `src/scripts.ts`. PostHog waits for measurement permission with
`loadMode: 'after-consent'`, and `cookieless_mode: 'never'` turns off its
cookieless capture. X Pixel waits for marketing permission.

<include src="../../shared/examples/javascript/scripts.mdx" />

Include the measurement and marketing categories in your Inth policy. Remove
any other loader for these vendors, such as a snippet in `index.html`, so each
one loads once and only through c15t.

## Start c15t

Call `init()` once, in your browser entry point:

<include src="../../shared/examples/javascript/init.mdx" />

`init()` returns the client. It reads stored choices, asks Inth for the
visitor's policy, shows the banner when the policy needs one, and loads each
script once its category is allowed. The banner renders in a shadow root with
its own styles, so you do not import a stylesheet. The client lasts for the
page; call `consent.dispose()` only if your app removes consent entirely.

When a visitor withdraws a permission they had given, the client saves the
choice and reloads the page, because code that already ran cannot be unloaded.
[Scripts](/docs/frameworks/javascript/scripts) explains how to change that.

## Change the look

Pass theme tokens in `ui.theme`. This version of `init()` turns the buttons
purple and rounds the cards:

<include src="../../shared/examples/javascript/theme.mdx" />

`theme` takes the same tokens as every c15t package; see
[tokens and CSS](/docs/customization/tokens). `presentation.prompt` changes the
banner's shape and position, `ui.css` adds CSS inside the shadow root, and
`i18n` changes the copy. The [customization overview](/docs/customization/overview)
explains which option fits which change.

## Next steps

- Render your own banner with the [headless runtime](/docs/frameworks/javascript/headless).
- Inspect consent with [DevTools](/docs/frameworks/javascript/dev-tools).
- Read consent from your code. `consent.has('measurement')` answers whether a
  category is allowed now, `consent.on('consent', listener)` reports changes,
  and `consent.save({ measurement: true })` records a choice. The
  `ConsentClient` type lists every method.

## Check it works

Run the app, open it in a private window, and open the browser's developer
tools on the Network tab.

1. Before you choose, filter for `posthog` and `ads-twitter`. There are no
   requests, and the YouTube iframe has no `src`.
2. Click **Reject all** and reload. The banner stays closed and the vendor
   requests stay absent.
3. Click **Privacy settings**, allow Measurement only and save. PostHog and
   the YouTube player load. X Pixel does not.
4. Open **Privacy settings** again and turn Measurement off. The page reloads,
   and PostHog and YouTube do not load again.

If no banner appears, see [troubleshooting](/docs/frameworks/javascript/troubleshooting).
Run the full [verification checklist](/docs/guides/verify-consent) before you
ship.
