## Install

<PackageCommandTabs mode="install" command="@c15t/core" />

## Initialize in the browser

```ts
import { createConsentKernel, createHostedTransport } from '@c15t/core';

const kernel = createConsentKernel({
  transport: createHostedTransport({
    backendURL: 'https://consent.example.com',
  }),
});

import { createPersistence } from '@c15t/core/modules/persistence';

const persistence = createPersistence({ kernel });
const unsubscribe = kernel.subscribe((snapshot) => {
  console.log(snapshot.effectivePermissions, snapshot.promptRequirement);
});
await kernel.commands.init();

// During application cleanup:
unsubscribe();
persistence.dispose();
kernel.dispose();
```

Construction has no browser effects. Attach persistence in the browser before
initialization. Hosted mode fetches the policy contract; offline mode uses a
local `createOfflineTransport({ policyRules })` instead. Configure browser modules
and UI separately. See the [kernel API](/docs/frameworks/javascript/api/overview).

## Record a direct choice

```ts
await kernel.commands.save('all');
await kernel.commands.save('none');
await kernel.commands.save({ measurement: true });
```

Wire each command to the corresponding user action. Object saves confirm only
the supplied categories. Use `commands.dismissNotice()` for a required notice;
a category save never dismisses one.

## Gate processing

```ts
import { evaluateConsent } from '@c15t/core';

if (evaluateConsent({ category: 'measurement' }, kernel.getSnapshot())) {
  // Start processing assigned to measurement.
}
```

Use the [script loader](/docs/frameworks/javascript/script-loader) for scripts
that must react to permission changes. Keep disclosure, preferences and opt-out
controls accessible even when `promptRequirement.kind` is `none`.
