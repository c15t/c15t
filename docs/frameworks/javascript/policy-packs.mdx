## Offline rules

```ts
import { createConsentKernel, createOfflineTransport } from '@c15t/core';
import { policyRulePresets } from '@c15t/schema';

const kernel = createConsentKernel({
  transport: createOfflineTransport({
    policyRules: [policyRulePresets.europeOptIn()],
  }),
});
await kernel.commands.init();
console.log(kernel.getSnapshot().resolution);
```

Offline initialization computes the rule once without a network request. The
Europe preset includes an unknown-geography fallback. Known unmatched geography
still fails closed. To allow processing by default without a prompt, explicitly
configure an opt-out rule with `prompt: 'none'` after reviewing your purposes.

Hosted transports read `policyResolution` from `/init`. Omission and malformed
payloads fail validation; explicit `policy: null` clears stale policy state.
See [policy concepts](/docs/frameworks/javascript/concepts/policy-packs) for
reviewed presets and [v3 migration](/docs/upgrade-v3) for rollout requirements.
