The kernel exposes two subscription surfaces:

- `subscribe()` receives every immutable snapshot update.
- `events.on()` receives one named lifecycle event.

## Subscribe to Consent State

Keep the previous snapshot when an integration should only run after consent
actually changes:

```ts
let previous = kernel.getSnapshot();

const unsubscribe = kernel.subscribe((snapshot) => {
  if (snapshot.consents !== previous.consents) {
    analytics.syncConsent(snapshot.consents);
  }

  previous = snapshot;
});

// Later, when the integration is removed
unsubscribe();
```

## Subscribe to Lifecycle Events

Use the typed event bus for command results and failures:

```ts
const stopInit = kernel.events.on('init:applied', ({ snapshot }) => {
  console.log('Country:', snapshot.location?.countryCode);
  console.log('Language:', snapshot.translations?.language);
});

const stopSave = kernel.events.on('command:save:completed', ({ result }) => {
  console.log('Consent saved:', result.ok);
});

const stopErrors = kernel.events.on('command:error', ({ command, error }) => {
  errorReporter.captureException(error, { extra: { command } });
});

// Remove listeners during teardown
stopInit();
stopSave();
stopErrors();
```

Event listeners only receive future events. Read `kernel.getSnapshot()` when
you also need the current state at registration time.
