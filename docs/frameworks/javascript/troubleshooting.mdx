## Kernel Not Accessible

**Symptom:** Code that reads `kernel.getSnapshot()` cannot access the kernel.

**Fixes:**

Create the kernel in a module and export that instance to every consumer:

```ts
import { createConsentKernel, createHostedTransport } from 'c15t';

export const kernel = createConsentKernel({
  transport: createHostedTransport({
    backendURL: 'https://your-instance.c15t.dev',
  }),
});

await kernel.commands.init();
console.log(kernel.getSnapshot());
```

The kernel is not installed on `window`. If browser-console access is useful
during development, assign it explicitly in your application code.

## Still Stuck?

- Subscribe to `kernel.events.on('command:error', ...)` to inspect failures
- Inspect `kernel.getSnapshot()` in the browser console
- Check the [GitHub issues](https://github.com/c15t/c15t/issues) for known bugs
