## Read Resolved Translations

Hosted mode returns the language and translation bundle selected by the
backend:

```ts
import { createConsentKernel, createHostedTransport } from 'c15t';

const kernel = createConsentKernel({
  transport: createHostedTransport({
    backendURL: 'https://your-instance.c15t.dev',
  }),
});

await kernel.commands.init();

const { translations } = kernel.getSnapshot();
console.log(translations?.language);
console.log(translations?.translations);
```

For offline mode, pass a translation bundle to `createOfflineTransport()`.

## Changing Language

Switch the active language at runtime with `setLanguage()`:

```ts
// Switch to German
kernel.set.language('de');
await kernel.commands.init();

// Build a language switcher
document.getElementById('lang-select')?.addEventListener('change', async (e) => {
  const lang = (e.target as HTMLSelectElement).value;
  kernel.set.language(lang);
  await kernel.commands.init();
});
```

Calling `commands.init()` after `set.language()` asks the transport to resolve
the new language.
