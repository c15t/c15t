## Read translations

```ts
console.log(kernel.getSnapshot().translations);
```

Hosted initialization returns resolved translations. Provider adapters accept
`i18n` for local messages and locale selection. Headless applications render the
translation bundle from the kernel and own their text components.

Changing cosmetic wording or layout does not record consent. If changed legal
copy must invalidate a prior interaction, update the policy's `copyRevision` and
rebuild its manifest. Applications read `promptRequirement`; they do not compare
fingerprints.
