The promoted kernel does not reload the page automatically. If your app needs a
reload after revocation, compare snapshots and apply that policy explicitly:

```ts
import { createConsentKernel, has } from 'c15t';

const kernel = createConsentKernel();
let previous = kernel.getSnapshot();

kernel.subscribe((snapshot) => {
  const revokedMeasurement =
    has('measurement', previous.consents) &&
    !has('measurement', snapshot.consents);

  previous = snapshot;
  if (revokedMeasurement) {
    analytics.flush();
    window.location.reload();
  }
});
```

<Callout type="info">
  The reload and deferred sync are part of the broader initialization flow. See [Initialization Flow](/docs/frameworks/javascript/concepts/initialization-flow) for the full sequence.
</Callout>

<Callout type="warn">
  The script loader removes scripts after consent is revoked unless a script uses `persistAfterConsentRevoked`. A reload may still be needed when a third-party SDK cannot be shut down cleanly.
</Callout>
