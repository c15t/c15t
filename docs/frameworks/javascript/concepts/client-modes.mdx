## Hosted and offline

Use `createHostedTransport({ backendURL })` for a backend or
`createOfflineTransport({ policyRules })` for local rules. Pass the transport to
`createConsentKernel({ transport })`. Attach browser persistence separately.

Hosted initialization reads the versioned backend contract and can sync receipts
and privacy directives with an established subject. Offline resolution makes no
network requests. Cookie projections still support server rendering, but offline
mode has no central record history or trusted cross-profile identity linkage.

Custom transports implement `KernelTransport`, including canonical init, receipt
and privacy behavior. They must not synthesize confirmation times or interpret a
missing policy as a successful no-match. See the [quickstart](/docs/frameworks/javascript/quickstart)
and [v3 migration](/docs/upgrade-v3).
