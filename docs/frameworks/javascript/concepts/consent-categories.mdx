<import src="../../../shared/concepts/consent-categories.mdx#overview" />

The resolved policy determines which categories are active. Hosted mode loads
that policy from your backend:

```ts
import { createConsentKernel, createHostedTransport, has } from 'c15t';

const kernel = createConsentKernel({
  transport: createHostedTransport({
    backendURL: 'https://your-instance.c15t.dev',
  }),
});

await kernel.commands.init();
```

<import src="../../../shared/concepts/consent-categories.mdx#categories-table" />

Check a category or condition with `has()`:

```ts
const { consents } = kernel.getSnapshot();

if (has('measurement', consents)) {
  // Safe to load analytics scripts
}

// Complex conditions
if (has({ and: ['measurement', 'marketing'] }, consents)) {
  // Both measurement and marketing are granted
}
```

<import src="../../../shared/concepts/consent-categories.mdx#configuration" />

Read the current policy scope from the snapshot:

```ts
const { policyCategories, policyScopeMode } = kernel.getSnapshot();
console.log(policyCategories, policyScopeMode);
```
