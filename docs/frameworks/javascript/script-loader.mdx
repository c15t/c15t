## Basic Usage

Pass an array of `Script` objects to the runtime options:

```ts
import { getOrCreateConsentRuntime } from 'c15t';
import { metaPixel } from '@c15t/scripts/meta-pixel';

const { consentStore } = getOrCreateConsentRuntime({
  mode: 'hosted',
  backendURL: 'https://your-instance.c15t.dev',
  scripts: [
    metaPixel({ pixelId: '123456' }),
    {
      id: 'custom-analytics',
      src: 'https://cdn.example.com/analytics.js',
      category: 'measurement',
    },
  ],
});
```

## Dynamic Script Management

Add, remove, or check scripts at runtime via the store:

```ts
const state = consentStore.getState();

// Add scripts dynamically
state.setScripts([
  { id: 'dynamic', src: 'https://cdn.example.com/widget.js', category: 'measurement' },
]);

// Remove a script
state.removeScript('dynamic');

// Check if a script is loaded
const loaded = state.isScriptLoaded('custom-analytics');

// Get all loaded script IDs
const allLoaded = state.getLoadedScriptIds();
```

## Effective permissions and expiry

Kernel script loaders use `effectivePermissions`. Saved grants can expire or be
restricted by the active policy, a detected GPC signal or a standing opt-out
directive. Removing the browser signal does not remove a recorded directive.
Browser detection accepts only `navigator.globalPrivacyControl === true`;
developer overrides remain separate from detection.

Script, iframe and network gates check expiry at use time. Kernel lifecycle
refresh also removes scripts and iframe sources when a grant expires. A fresh
confirmation restores eligible iframe sources. Necessary permissions remain
granted, including Google Consent Mode's default `security_storage` mapping.

Consent-aware script callbacks receive effective permissions when individual
categories change, even when the script's overall consent condition stays true.
This lets Google Consent Mode update analytics and advertising independently.
Category-only `or` conditions retain their usual semantics. IAB targets also
require confirmed TC authority and apply every referenced category restriction.
