---
title: Iframe blocking
description: Keep iframe URLs inactive until their category permits processing.
---

## Mark the iframe

```html
<iframe
  data-src="https://www.youtube-nocookie.com/embed/VIDEO_ID"
  data-category="experience"
  title="Video"
></iframe>
```

Start with `data-src` rather than `src` so the browser does not request the embed
before the blocker runs. Include the category in the policy scope.

## Attach the blocker

```ts
import { createIframeBlocker } from '@c15t/core/modules/iframe-blocker';

const blocker = createIframeBlocker({ kernel });
```

Reuse the kernel from the [quickstart](/docs/frameworks/javascript/quickstart).
The blocker observes added frames, checks effective permissions and removes the
active source when permission expires or becomes restricted. Call
`blocker.processAllIframes()` for an explicit rescan and `blocker.dispose()` at
teardown. Display a preferences link beside blocked content; a placeholder click
must not manufacture a category choice.

For React and Next.js, use [Frame](/docs/frameworks/react/components/frame).
