## Read resolved data

```ts
const snapshot = kernel.getSnapshot();
console.log(snapshot.location, snapshot.subject, snapshot.resolution);
```

For a deterministic preview, set `kernel.set.overrides({ country: 'DE' })` and
run `kernel.commands.init()` again. Overrides are test inputs, not browser GPC
detection. Policy resolution decides behavior; a country name alone does not.

## Identify

```ts
await kernel.commands.identify({
  id: 'account-123',
  identityProvider: 'application',
});
```

Use a non-secret identifier. Local identification can complete before a server
subject exists. The transport queues the association until a real subject is
established; it never creates consent merely to obtain a subject ID. Pending
identity and privacy work is cancelled by clear or disposal. Do not report server
persistence until the relevant endpoint responds successfully.

An anonymous detected GPC directive stays local. Once a server subject exists,
the transport can forward it through the separate privacy endpoint. Associated
profile propagation requires trusted server identity linkage; a browser-provided
external ID is not that trust.
