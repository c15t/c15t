## Create a Kernel

`createConsentKernel()` creates one isolated consent state container. Kernel
construction has no network, storage, DOM, or global side effects.

```ts
import { createConsentKernel, createHostedTransport } from 'c15t';

const kernel = createConsentKernel({
  transport: createHostedTransport({
    backendURL: 'https://your-instance.c15t.dev',
  }),
});

await kernel.commands.init();
```

For a browser-only setup, use the offline transport:

```ts
import { createConsentKernel, createOfflineTransport } from 'c15t';

const kernel = createConsentKernel({
  initialOverrides: { country: 'DE' },
  transport: createOfflineTransport(),
});

await kernel.commands.init();
```

## Read and Subscribe

`getSnapshot()` returns an immutable snapshot. `subscribe()` runs whenever the
snapshot changes and returns an unsubscribe function.

```ts
const snapshot = kernel.getSnapshot();
console.log(snapshot.consents.measurement);
console.log(snapshot.policy?.id);

const unsubscribe = kernel.subscribe((next) => {
  console.log(next.consents);
});

unsubscribe();
```

## Update and Save Consent

Synchronous setters update local state. Commands perform transport work.

```ts
kernel.set.consent({ measurement: true, marketing: false });
kernel.set.overrides({ country: 'DE', language: 'de' });

const result = await kernel.commands.save('custom');
if (!result.ok) {
  console.error('Consent could not be saved');
}
```

Use `kernel.commands.identify()` when an authenticated identity becomes
available:

```ts
await kernel.commands.identify({
  externalId: user.id,
  identityProvider: 'auth0',
});
```

## Optional Browser Modules

Persistence, script loading, iframe blocking, network blocking, and window
debugging are separate opt-in modules. This keeps the kernel safe to construct
in server and edge runtimes.
