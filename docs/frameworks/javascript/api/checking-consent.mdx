## Evaluate a gate

```ts
import { evaluateConsent, type ConsentKernel } from '@c15t/core';

export function canMeasure(kernel: ConsentKernel) {
  return evaluateConsent({ category: 'measurement' }, kernel.getSnapshot());
}
```

The evaluator applies current expiry, policy scope, denials and privacy directives.
Category conditions support `and`, `or` and `not`. IAB targets additionally need
confirmed TC authority; an editable vendor map is not authority.

Read `explicitChoice` to inspect confirmed decisions and `promptRequirement` to
render outstanding interaction. Neither receipt presence nor hidden UI permits
processing. Use the built-in script, iframe and network gates to react to updates.
