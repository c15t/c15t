## `commands.save(input)`

Batch-save consent preferences. This is the primary way users grant or deny consent.

```ts
// Accept all categories
await kernel.commands.save('all');

// Accept only necessary (reject everything else)
await kernel.commands.save('none');

// Save a custom selection
await kernel.commands.save({ measurement: true, marketing: false });
```

| Type | Behavior |
|------|----------|
| `'all'` | Sets all configured categories (those in `consentCategories`) to `true` and saves |
| `'none'` | Sets only `necessary` to `true`, all others to `false`, and saves |
| Partial consent object | Merges the supplied categories and saves the result |

The configured transport receives the save. Add `createPersistence({ kernel })`
in browser code when consent should also be stored locally.

## `set.consent(input)`

Update one or more categories synchronously without running the transport save.

```ts
kernel.set.consent({ measurement: true });

// Persist the current state afterward
await kernel.commands.save();
```

Use `commands.save({ measurement: true })` when a single action should update and
persist in one call.

## Stage Preference-Dialog Changes

The kernel only stores committed consent. Keep draft selections in your UI, then
pass the completed draft to `commands.save()`:

```ts
const draft = {
  ...kernel.getSnapshot().consents,
  measurement: true,
  marketing: false,
};

// User clicks "Save" — persist the staged selections
await kernel.commands.save(draft);
```

## Reset Consent

Reset all consent preferences to their defaults. This clears stored consent and returns the user to an unconsented state.

```ts
import { createPersistence } from 'c15t/modules/persistence';

const persistence = createPersistence({ kernel });
persistence.clear();
kernel.set.consent({
  necessary: true,
  functionality: false,
  measurement: false,
  experience: false,
  marketing: false,
});
kernel.set.hasConsented(false);
kernel.set.activeUI('banner');
```

## Full Preference Dialog Flow

Here's a typical flow for a preference dialog:

```ts
import { createConsentKernel, createHostedTransport } from 'c15t';

const kernel = createConsentKernel({
  transport: createHostedTransport({
    backendURL: 'https://your-instance.c15t.dev',
  }),
});

await kernel.commands.init();

// 1. User opens the preference dialog
kernel.set.activeUI('dialog');

// 2. Copy the current state into UI-local draft state
const draft = { ...kernel.getSnapshot().consents };
draft.measurement = true;
draft.marketing = false;

// 3. User clicks "Save"
await kernel.commands.save(draft);

// 4. Close the dialog
kernel.set.activeUI('none');
```
