## Save a choice

```ts
import type { ConsentKernel } from '@c15t/core';

export async function saveMeasurement(kernel: ConsentKernel, value: boolean) {
  return kernel.commands.save({ measurement: value });
}
```

`save('all')` accepts the active selectable scope. `save('none')` rejects that
scope. An object confirms exactly its own optional keys, including unchanged
values; omitted receipts keep their time and policy basis. An empty object is a
successful no-op. Positive out-of-scope keys and `necessary: false` reject the
whole operation. Necessary is always effectively allowed.

No-input `save()` confirms the current unmasked selection for the selectable
scope. Preference forms should pass their displayed draft explicitly. Do not
copy effective permissions into a form; GPC may mask an explicit grant.

The choice records locally before remote completion. Failed saves and retries
keep the original action time. Check the returned `ok` result. A partial save
can succeed while other categories still require a choice.

## Dismiss a notice

`commands.dismissNotice()` succeeds only while a notice is required. It writes a
separate local dismissal and changes no permission. Preference saves remain
available and do not dismiss the notice.

## Clear local records

Use the persistence handle's `clear()` to remove choices, notice dismissal,
privacy directives and pending writes. A live GPC signal still masks applicable
permissions. Clearing local state does not erase server audit records.
