## Configuration

Add `clearOnRevocation` to your runtime options:

```ts
import { getOrCreateConsentRuntime } from 'c15t';

const { consentStore } = getOrCreateConsentRuntime({
  mode: 'hosted',
  backendURL: 'https://your-instance.c15t.dev',
  clearOnRevocation: {
    marketing: {
      cookies: ['_fbq', '_fbp'],
    },
    measurement: {
      cookies: ['_ga', '_ga_*'],
      localStorage: ['ga_disable_*'],
    },
  },
});
```

## Runtime Updates

Update the configuration at runtime - this immediately sweeps any category that is already denied:

```ts
const state = consentStore.getState();

state.setClearOnRevocation({
  marketing: {
    cookies: ['_fbq', '_fbp', 'new-tracker-cookie'],
  },
});
```
