## Register scripts on the provider

Pass the array from `src/scripts.ts` to `ConsentManagerProvider` as the
`scripts` prop. The [quickstart](/docs/frameworks/svelte/quickstart) sets up
this file:

<include src="../../shared/examples/svelte/scripts.mdx" />

Replace the placeholder PostHog project key with your own.

The provider loads the script loader as a separate chunk, shared with the
[network blocker](./network-blocker), and only when `scripts` is not empty or
the blocker has rules, so an app with neither never downloads it. A
single-page app has no server render to link the chunk from, so the browser
requests it after your app's JavaScript has run. A SvelteKit app can preload
it from the server-rendered page; the SvelteKit scripts guide shows how.
