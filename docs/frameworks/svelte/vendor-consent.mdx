## Declare the vendors

Built-in `@c15t/integrations` helpers already list their vendor by name, so
you only declare a vendor for a script of your own, or to replace a helper's
name and privacy policy.

Declare the vendors next to the scripts in `src/scripts.ts`, using the `vendor`
slug each script already carries:

{/* example: fragment */}

```ts title="src/scripts.ts (partial)"
import type { ConsentManagerOptions } from '@c15t/svelte';

export const vendors: NonNullable<ConsentManagerOptions['vendors']> = [
	{
		id: 'x-pixel',
		name: 'X Pixel',
		category: 'marketing',
		privacyPolicyUrl: 'https://x.com/privacy',
	},
];
```

Then pass them to `ConsentManagerProvider` in `src/App.svelte`:

{/* example: fragment */}

```svelte title="src/App.svelte (partial)"
<script lang="ts">
  import { scripts, vendors } from './scripts';
</script>

<ConsentManagerProvider {mode} {scripts} {vendors}>
```

The provider reads `vendors` once, when it is created.

`ConsentGate` checks a category only. For an iframe, add `data-vendor` and use
the iframe blocker; see [embeds](/docs/frameworks/svelte/embeds).

## Build your own vendor switch

`getConsentManager()` stages vendor switches on the same draft as the category
switches. `selectedVendors` has one value per declared vendor,
`setSelectedVendor(id, granted)` changes one, and `saveConsents('custom')`
records the draft:

{/* example: fragment */}

```svelte title="src/XPixelSwitch.svelte (partial)"
<script lang="ts">
	import { getConsentManager } from '@c15t/svelte';

	const consent = getConsentManager();
</script>

<input
	type="checkbox"
	checked={consent.selectedVendors['x-pixel'] ?? true}
	onchange={(event) =>
		consent.setSelectedVendor('x-pixel', event.currentTarget.checked)}
/>
<button type="button" onclick={() => consent.saveConsents('custom')}
	>Save</button
>
```

`saveConsents('custom')` throws when the policy changed since the draft
started. `vendorChoice.denied` lists the vendors the visitor recorded as off,
and `getDisplayedVendors(category)` returns the vendors to list under one
category. [Context getters](/docs/frameworks/svelte/getters) covers the draft.

## Check whether a vendor may run

`consent.isVendorAllowed(id)` on the object from `getConsentManager()` returns
`true` while the vendor may run: it is declared, its category is allowed and
the visitor has not switched it off. Read it in markup or a `$derived` so it
updates when consent changes.
