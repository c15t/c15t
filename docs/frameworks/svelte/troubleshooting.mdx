## The app throws "Set `VITE_C15T_BACKEND_URL`"

`src/App.svelte` throws when the backend URL is empty. Add
`VITE_C15T_BACKEND_URL` to `.env.local` and restart Vite; Vite reads env
files only at startup and build. In production, set it where you run the
build, because Vite writes the value into the bundle.

## The banner appears after the page

In a Svelte app without a server, the browser requests the policy after the
page loads, then shows the banner. That is expected. Optional categories stay
denied until the policy arrives. For a banner in the first HTML, the page has
to be server-rendered; SvelteKit does that. See
[choose your setup](/docs/concepts/choose-your-setup).
