## Find a comparison for your consent project

Use the [consent tool comparisons](/docs/comparisons) to compare c15t v3 with
hosted CMPs and browser libraries. Each comparison identifies the product scope,
links to reviewed official sources and gives a concrete evaluation task.

Start with [Cookiebot](/docs/comparisons/cookiebot) for scanning and hosted
website workflows, [OneTrust](/docs/comparisons/onetrust) for cookie inventory
operations, or [CookieConsent v3](/docs/comparisons/cookieconsent-v3) for a
browser library with application-owned logging. The
[full comparison index](/docs/comparisons) includes the other tools.

For a c15t prototype, follow the [framework setup](/docs/frameworks) with
[Inth](https://inth.com), then verify an optional vendor before and after
rejection. Compare the working result and operating requirements before
choosing a tool.
