Add the v3 policy rule contract. `PolicyRule` declares a permission model (`opt-in`, `opt-out`, `iab`) and a first-layer prompt (`choice`, `notice`, `none`) separately, with explicit category scope, required actions and accept/reject equivalence, persistent rights, independent choice and notice validity, an explicit `privacySignals.gpc.denyCategories` mapping, and an author-controlled `copyRevision`. `normalizePolicyRule`, `inspectPolicyRules` and `validatePolicyRules` canonicalize and validate rules; validation reads own fields only and rejects unknown fields, invalid model and prompt pairs, unknown categories and out-of-scope GPC mappings.

Add three separately versioned fingerprint domains (`createPolicyRuleFingerprints`: `policy`, `choice`, `notice`) that exclude presentation, plus an optional diagnostics-only `createPresentationFingerprint`. The v2 `createPolicyFingerprint` and `createMaterialPolicyFingerprint` keep their exact bytes; `createMaterialPolicyFingerprintSync` is the synchronous twin.

Add versioned policy resolution: `resolvePolicyRules` returns `unconfigured`, `matched`, `no-match` or `failed` with an explicit nullable `policy`, `/init` carries it as `policyResolution` (contract version 1, request header `x-c15t-policy-contract`), `readPolicyResolutionWire` is a strict client reader that fails safely on unknown versions or values, and `safeFallbackPolicyRule` plus its pinned `SAFE_FALLBACK_POLICY_FINGERPRINTS` describe the strict opt-in choice fallback used for every non-matched outcome.

Manifests move to `schemaVersion: 2`. `buildConsentManifestFromConfig` accepts `policyRules`, precomputes rule fingerprints per pack, records invalid configuration as `policyFailure` instead of throwing, and still fills the v2 `policy`, `resolvedPolicy` and `fingerprint` fields for older clients. Rules the v2 shape cannot carry without widening permissions project to the strictest v2 shape; `describeLegacyProjection` reports what an old client loses, and it is a description, not a safety guarantee for old runtimes. Legacy `policyPacks` are lifted through the clearly named bridge (`liftLegacyPolicyConfig`, `projectPolicyRuleToLegacy`, `readLegacyPolicyWire`), which is scheduled for removal in the v3 final sweep.

Add `policyRulePresets` (`europeOptIn`, `europeIab`, `californiaOptIn`, `californiaOptOut`, `quebecOptIn`, `worldOptOutNoPrompt`) with review metadata. `worldOptOutNoPrompt` replaces the `worldNoBanner` model shortcut with an explicit opt-out rule without a first-layer prompt. Add the `SubjectChoiceWire` receipt schemas so `POST /subject` can carry one confirmed decision per category with its own confirmation time and policy basis.
