Add `@c15t/react-native`, the React Native consent SDK backed by native Swift and Kotlin consent cores. Consent state lives natively, so it hydrates from protected storage and answers gating checks before the JavaScript bundle runs, and it survives restarts and offline runs through a persisted save queue. Includes the provider and hooks, headless components for custom UI, and the protocol for the native bridge. IAB TCF is not part of this first release.
