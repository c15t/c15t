@c15t/browser script-tag example

A plain page with a hostile theme: every button is pink with a dashed lime border. The banner, the preference centre and the DevTools panel each render in a shadow root and ignore it. Everything below is gated on consent; watch the log as you accept, reject and customise.

Page hooks

Any element can drive the banner with data-c15t-action, and a link to #c15t-preferences opens the preference centre. No JavaScript on the page.

Gated iframes
