Custom UI on the headless build

This page loads c15t.headless.js: the same runtime, storage, script gating and window.c15t API as the main page, but no banner and no CSS. The card in the corner is the site's own HTML, styled by the site's own stylesheet, the way zed.dev/docs ships its consent banner on c15t.

The wiring is small. Accept and reject are data-c15t-action buttons, so they need no code. The rest is one listener on ui to show, hide and switch the card into configure mode, one on consent to keep the switches honest, and c15t.save() on the Save button.

Compare with the prebuilt banner. Change the country on the DevTools Location tab to see the same policy switch drive this UI.
